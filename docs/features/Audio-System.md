# Audio-System

## 1. 概要
オーディオ・BGMシステムは、RogueFにおけるゲーム内の臨場感、緊張感、および没入感を高めるための音響制御メカニズムです。
本システムは、プレイヤーの環境設定（マスター・BGM・SE音量）の保存、状況変化に応じた動的なBGM切り替えアルゴリズム、空間的な音量減衰（SEの距離減衰）、および重複音源の同時再生制限を統括します。

## 2. 音量設定 (Volume Configurations)
プレイヤーはシステム設定画面から、ゲーム全体の音量を個別に調整できます。これらの設定はプレイヤーの永続的なデータ（セーブデータ）の一部として保存されます。

### 2.1 音量パラメータ
音量は `0`（消音）から `100`（最大）の範囲で、1 刻みで設定可能です。
- **マスター音量 (`masterVolume`)**: ゲーム全体のすべての音声出力に対するマスター乗数。デフォルト値: `80`。
- **BGM音量 (`bgmVolume`)**: バックグラウンドミュージック（背景音楽）の音量乗数。デフォルト値: `80`。
- **SE音量 (`seVolume`)**: サウンドエフェクト（効果音）の音量乗数。デフォルト値: `80`。

### 2.2 最終出力音量の算出式
スピーカーから実際に出力される実効音量は、以下の計算式で決定されます。

$$\text{実効BGM音量} = \text{基本BGM音量} \times \left(\frac{\text{masterVolume}}{100}\right) \times \left(\frac{\text{bgmVolume}}{100}\right)$$

$$\text{実効SE音量} = \text{基本SE音量} \times \left(\frac{\text{masterVolume}}{100}\right) \times \left(\frac{\text{seVolume}}{100}\right) \times \text{空間減衰率}$$

## 3. 動的BGM遷移 (Dynamic BGM Transition)
プレイヤーの現在位置や状態、脅威度に応じて、BGMは自動的かつシームレスに切り替わります。

### 3.1 優先度ルール
複数のBGM切り替えトリガーが同時に発生した場合、以下の**優先度順位**に従って、最も優先度の高いトラックが選択・再生されます。

| 優先度 | 状態・イベント | 再生されるBGMトラック | 説明 |
| :---: | :--- | :--- | :--- |
| **1 (最高)** | **ピンチ状態 (Danger)** | `bgm_danger` (ピンチ専用曲) | プレイヤーのHPまたは満腹度（食料）が危険域に達している状態。 |
| **2** | **PK介入発生 (PK Intervention)** | `bgm_pker_battle` (PK対決曲) | PKer（侵入者）がフロアに存在し、戦闘行動圏内にいる、またはマッチング中。 |
| **3** | **ダンジョン探索 (Dungeon Biome)** | バイオーム別BGM (後述) | 探索中フロアのバイオームに応じた固有の環境音楽。 |
| **4 (最低)** | **拠点・街 (Town/Base)** | `bgm_town` (日常・拠点曲) | 安全地帯である拠点（ベース施設）に滞在している状態。 |

### 3.2 状態の定義と判定基準

#### A. ピンチ状態 (Danger)
以下のいずれかの条件を満たしたとき、ピンチ状態となり `bgm_danger` へ遷移します。
- プレイヤーのHPが最大HPの **20% 以下** (`hp <= maxHp * 0.2`)。
- プレイヤーの満腹度（Satiety）が **0**。かつ、飢餓によるHPスリップダメージが発生している状態。

#### B. PK介入発生 (PK Intervention)
以下のいずれかの条件を満たしたとき、緊迫した `bgm_pker_battle` へ遷移します。
- PKer（プレイヤー・キラー）が同じフロアに出現し、プレイヤーの視界範囲（標準 11×11 マス）に進入したとき。
- PKerがプレイヤーへの追跡・攻撃行動を開始したとき。

#### C. バイオーム別BGM (Dungeon Biome)
ダンジョン（フロンティア、マイ・ダンジョン共通）では、設定されたバイオームに応じて以下の専用BGMが再生されます。
- **洞窟バイオーム (`cave`)**: `bgm_dungeon_cave` (神秘的で静かな洞窟の曲)
- **森林バイオーム (`forest`)**: `bgm_dungeon_forest` (ざわざわとした風や葉の音が混じる神秘的な曲)
- **氷雪バイオーム (`ice`)**: `bgm_dungeon_ice` (静寂と冷たさを感じさせる澄んだ曲)
- **溶岩バイオーム (`lava`)**: `bgm_dungeon_lava` (重低音と太鼓が響く焦燥感を煽る曲)

### 3.3 フェード効果
BGMの切り替え時は、急激な音変化による不快感を防ぐため、**1.5秒間のクロスフェード（フェードアウト ＆ フェードイン）** を行います。

## 4. SE空間音量減衰 (SE Spatial Attenuation)
ダンジョン内で発生する効果音（モンスターの咆哮、トラップの作動音、攻撃音など）は、プレイヤーと音源（発生元）との距離に応じて音量が減衰します。

### 4.1 距離の測定
距離はチェビシェフ距離（斜め移動を1歩とするローグライク仕様の距離測定）を使用して算出します。プレイヤーの座標を $(x_p, y_p)$、音源の座標を $(x_s, y_s)$ としたとき、距離 $d$ は以下のように計算されます。

$$d = \max(|x_p - x_s|, |y_p - y_s|)$$

### 4.2 空間減衰率の計算式
可聴最大半径を $R = 8$ マスと定義します。距離 $d$ に応じた空間減衰率は以下の通りです。

$$\text{空間減衰率} = \max\left(0, 1 - \frac{d}{R}\right)$$

- $d \le 1$ （隣接または自身）：減衰なし（空間減衰率 = `1.0`）
- $1 < d < R$ ：距離に応じて線形に音量が減衰（例: $d=4$ の場合、空間減衰率 = `0.5`）
- $d \ge R$ （可聴範囲外）：消音（空間減衰率 = `0.0`、再生そのものをスキップしてリソースを節約）

## 5. 同時再生制限 (Concurrent Playback Limiter)
強力な範囲攻撃や、モンスターハウスなどで大量の同一効果音（例：爆発音、打撃音）が同時に発生した際、音割れや不快な雑音を防ぐための制限を設けます。

- **最大同時再生数**: 同一の効果音ID（例: `se_explosion`）について、同時に再生できる上限は **最大 3 音** までとします。
- **割り込み制御ルール**: 4音目以降の同一効果音の再生リクエストが発生した場合、以下のいずれかの処理を行います。
  1. すでに再生中の3音のうち、最も再生残り時間が短い音、または音量が小さい音（距離が遠い音）を強制終了（停止）し、新しい効果音を再生する。
  2. 新しいリクエストを無視（破棄）する。

## 6. データモデルの拡張
音量設定情報は、プレイヤーのセーブデータや状態管理の一部として組み込まれます。
詳細な定義は、**[セーブ・ロードシステム](Save-Load-System.md)** および **[インベントリシステム](Inventory-System.md)** とも密接に関連します。

### 6.1 TS型定義 (`src/@types/player.d.ts`) の追加
プレイヤー情報に音量設定を保持するため、以下のプロパティを追加・拡張します。

```typescript
interface AudioSettings {
  masterVolume: number; // 0〜100
  bgmVolume: number;    // 0〜100
  seVolume: number;     // 0〜100
}

declare class Player {
  // 既存プロパティ
  id: string;
  name: string;
  // (中略)

  // オーディオ設定の追加
  audioSettings: AudioSettings;
}
```
