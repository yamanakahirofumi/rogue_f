# Audio-System

## 1. 概要
RogueF のオーディオ＆BGMシステムは、ゲーム内の臨場感、没入感、および状況の緊迫度を聴覚的に伝えるための基幹システムです。
プレイヤーの音量設定、エリアやバイオームに応じた動的なBGM遷移、状況の危機度（低HP・空腹）に応じた危険警告BGM、PK（プレイヤーキラー）介入時の戦闘BGM、および3D空間（2Dグリッドマップ）における効果音（SE）の距離減衰と同時再生制限を制御します。

## 2. 音量設定と保存
ユーザーはゲーム内の設定画面から各種音量を個別に調整できます。これらの設定はプレイヤー状態データおよびローカルストレージ（Local Storage）に保存され、セッションを跨いで永続化されます。

### 2.1 音量カテゴリ
音量は以下の3つのカテゴリで個別に設定および管理されます。各音量は `0.0` (無音) から `1.0` (最大音量) の範囲の浮動小数点数で定義されます。

| 音量設定 | 役割 | 既定値 |
| :--- | :--- | :--- |
| **マスター音量 (Master Volume)** | ゲーム全体の最終的な音量を決定する主音量。 | `0.8` |
| **BGM音量 (BGM Volume)** | バックグラウンドミュージック（背景音楽）の音量。マスター音量に乗算されます。 | `0.7` |
| **SE音量 (SE Volume)** | 効果音（移動、攻撃、被弾、アイテム使用、トラップ発動等）の音量。マスター音量および距離減衰に乗算されます。 | `0.9` |

### 2.2 最終出力音量の計算式
各音源の最終的な出力音量は以下の式に基づいて算出されます。

- **BGMの最終出力音量**:
  `最終BGM音量 = 設定BGM音量 * 設定マスター音量`

- **SEの最終出力音量**:
  `最終SE音量 = 設定SE音量 * 設定マスター音量 * 距離減衰率`

### 2.3 音量設定 of データ構造
音量設定は `src/@types/player.d.ts` 等のプレイヤー設定に以下のようなデータ構造で組み込まれます。

```typescript
interface AudioVolumeConfig {
  master: number; // 0.0 ~ 1.0
  bgm: number;    // 0.0 ~ 1.0
  se: number;     // 0.0 ~ 1.0
}
```

## 3. 動的 BGM 遷移ロジック
ゲームのシチュエーションやプレイヤーのステータス、現在位置、および突発的なイベント（PK介入など）に応じて、BGMは動的かつシームレスに遷移（クロスフェード等）します。

### 3.1 エリアおよびバイオームに基づく基本BGM
プレイヤーが滞在しているエリアおよび現在の階層のバイオーム設定に応じて、再生される基本BGMが決定されます。
バイオームの詳細は **[バイオーム・環境システム](Biome-System.md)** を参照してください。

| エリア / バイオーム | BGMタイプ | 特徴・雰囲気 |
| :--- | :--- | :--- |
| **拠点 / 街 (Town / Base-Facility)** | `bgm_town` | 平穏で安心感のある、アコースティック調のBGM。 |
| **洞窟バイオーム (`cave`)** | `bgm_dungeon_cave` | 不気味で静まり返った、環境音に近いダークアンビエント調のBGM。 |
| **森林バイオーム (`forest`)** | `bgm_dungeon_forest` | 自然の神秘と怪しさを感じさせる、ミステリアスな民族音楽調のBGM。 |
| **氷雪バイオーム (`ice`)** | `bgm_dungeon_ice` | 冷徹で透明感のある、ピアノやシンセサイザーを中心とした静寂なBGM。 |
| **溶岩バイオーム (`lava`)** | `bgm_dungeon_lava` | 緊迫感と熱気を感じさせる、ドラムや低音が強調された重厚なBGM。 |

### 3.2 危険状態（低HP・飢餓）によるBGM遷移
プレイヤーの生命が危機に瀕している場合、現在位置のBGMから**一時的に危険状態専用BGM（`bgm_danger`）へシームレスに遷移**します。
危険状態の判定は以下の優先度および条件に基づきます。

- **判定条件**:
  - **低HP状態**: 現在のHPが最大HPの **25% 未満** の状態。詳細は **[戦闘システム](Combat-System.md)** を参照してください。
  - **飢餓状態**: 現在の満腹度が **0** であり、HPが減少し始めている状態。詳細は **[満腹度システム](Hunger-System.md)** を参照してください。
- **遷移仕様**:
  - 上記いずれかの条件を満たした場合、現在のエリア/バイオームBGMは **2.0秒** かけてフェードアウトし、不協和音や心拍音を取り入れたテンポの速い警告用BGM（`bgm_danger`）がループ再生されます。
  - プレイヤーが回復薬の使用等によって危険状態から脱した場合、または死亡した場合は、再度 **2.0秒** かけて元の基本BGMに戻ります。

### 3.3 PK（プレイヤーキラー）介入時の戦闘BGM
他プレイヤー（PKer）が現在のフロアに乱入し、介入イベントが発生した場合、通常の探索用BGMは中断され、最も高い優先度で**PK戦闘専用BGM（`bgm_pk_battle`）へ遷移**します。
PK介入の詳細は **[PKシステム](PK-System.md)** を参照してください。

- **遷移仕様**:
  - PKerが乱入した瞬間、BGMは即座に（フェード時間 **0.5秒**）非常に激しく緊張感のある戦闘BGM（`bgm_pk_battle`）へと切り替わります。
  - PKerを撃破する、またはPKerが退出・脱出するか、プレイヤー自身がフロアから離脱（または死亡）するまで、このBGMが維持されます。

### 3.4 BGMの優先度一覧
複数の状態が重複して発生した場合、以下の優先度に従って再生されるBGMが決定されます。

1. **PK戦闘BGM (`bgm_pk_battle`)** [最優先]
2. **危険状態BGM (`bgm_danger`)**
3. **エリア・バイオーム基本BGM (Town / Cave / Forest / Ice / Lava)** [最底基準]

## 4. SE 空間音量減衰 (Spatial Attenuation)
RogueF のマップは2Dグリッドで構成されています。プレイヤーの視覚外、あるいは距離が離れた場所で発生したイベント（モンスターの咆哮、トラップ発動、壁の破壊等）の臨場感を再現するため、**音源とプレイヤーの距離（チェビシェフ距離）に基づく音量減衰**が適用されます。

### 4.1 距離計算式
音源の座標 $(X_s, Y_s)$ とプレイヤーの現在座標 $(X_p, Y_p)$ の間の距離 $D$ は、斜め移動のコストが一律であることを考慮し、**チェビシェフ距離 (Chebyshev Distance)** を使用して計算します。

`D = Math.max(Math.abs(Xs - Xp), Math.abs(Ys - Yp))`

### 4.2 減衰率の計算式と可聴半径
効果音には一律で **最大可聴半径 $R_{max} = 10$ マス** が定義されています。

- **距離 $D \le 1$ の場合 (プレイヤー自身または隣接マス)**:
  `距離減衰率 = 1.0` (音量減衰なし)
- **距離 $1 < D \le R_{max}$ の場合**:
  `距離減衰率 = 1.0 - (D - 1) / (Rmax - 1)`
- **距離 $D > R_{max}$ の場合**:
  `距離減衰率 = 0.0` (完全無音、再生処理自体をスキップ)

### 4.3 音響空間減衰の計算例

| プレイヤーからの距離 $D$ | 距離減衰率 | 音量イメージ |
| :--- | :--- | :--- |
| **0 ~ 1 マス** | `1.0` (100%) | プレイヤー自身の行動、あるいは真隣での出来事。最大音量。 |
| **3 マス** | `0.77` (77%) | 視界内の数マス先。やや小さく聞こえる。 |
| **6 マス** | `0.44` (44%) | 視界の境界線付近。遠くで発生した気配が伝わる。 |
| **9 マス** | `0.11` (11%) | 暗闇の向こう側。非常にかすかに聞こえる。 |
| **10 マス以上** | `0.00` (0%) | 遠すぎるため、完全に無音。 |

## 5. SE 同時再生制限 (Concurrent Playback Limiter)
戦闘中に多数のモンスターから攻撃を受ける、あるいはトラップが連鎖的に発動した際に、同じ効果音が同時に大量再生されることで発生する**スピーカーの音割れ（クリッピング）や極端な音量の増幅、リスナーの聴覚的不快感を防ぐため**、同時再生制限（ボイス制限）を適用します。

### 5.1 制限ルール
- **同一効果音の多重再生制限**: 同一のSE ID（例: `se_attack_hit_slashing`）について、同一フレーム（または 100ミリ秒 以内などの極めて短い判定バッファ時間内）における**最大同時発音数は 3音 まで**と制限します。
- **制限時の挙動（後着優先 / 先着優先）**: 制限数（3音）を超えて同じSEが再生要求された場合、**最も距離が近い（距離減衰率が小さい、つまりプレイヤーに近い）3音を優先**して再生し、最も遠い音（または4番目以降に要求された音）の再生要求は破棄（ミュート）されます。
- **総発音数制限 (Global Voice Limit)**: ゲーム全体で同時に再生できるSEの総数は、ハードウェア環境（ブラウザ等）の負荷軽減のため **最大 16音** とします。これを超える再生要求については、優先度の低い音、または再生開始から最も時間が経過している音が自動的にカットされます。
