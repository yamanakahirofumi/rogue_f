# Audio-System

## 1. 概要
オーディオ・BGMシステムは、RogueF の世界における没入感と臨場感を最大化し、音を通じた状況把握などのゲームプレイ上の重要なシグナル（戦略的ヒント）をプレイヤーに提供する仕組みです。本システムは、BGMの動的遷移、SEの空間的な音量減衰、同時再生制限、およびプレイヤーの音量設定の永続化を定義します。

## 2. 音量設定と保存
プレイヤーおよび管理者は、ゲーム内の設定画面から個別に音量を調整できます。設定値はローカルストレージおよびサーバー上のプレイヤー状態データに保存（永続化）されます。

### 2.1 音量カテゴリ
システムは以下の 3 つの独立した音量チャンネルを持ちます。

- **マスターボリューム (Master Volume)**:
  - ゲーム全体の最終出力を制御（0% 〜 100%、デフォルト: 80%）
- **BGMボリューム (BGM Volume)**:
  - 背景音楽の音量を制御（0% 〜 100%、デフォルト: 70%）
- **SEボリューム (SE Volume)**:
  - 効果音（歩行音、攻撃音、スキル、トラップ、ボタン操作等）の音量を制御（0% 〜 100%、デフォルト: 80%）

### 2.2 状態永続化
音量設定は、[セーブ・ロードシステム](Save-Load-System.md)を通じて、プレイヤーの環境設定オブジェクト（`AudioConfig`）としてシリアライズされ、セーブデータに保存されます。

## 3. ダイナミックBGM遷移ロジック
ゲームの状況変化に応じて、BGMは自動的かつシームレスに切り替わります。急激な音の変化を防ぐため、すべてのBGM遷移は **1.5秒のクロスフェード（フェードアウトとフェードインの同時実行）** を使用して行われます。

### 3.1 エリア遷移
プレイヤーが現在いるエリア（拠点 or ダンジョン）に応じて基本となるBGMトラックが決定されます。
- **拠点・町 (Town/Base)**:
  - 穏やかで活気のあるアコースティックなBGM。安心感と準備を促す曲調。
- **ダンジョン (Dungeon)**:
  - 探索の緊張感を高めるミステリアスな環境音楽。

### 3.2 バイオーム対応
ダンジョン探索時、現在のフロアのバイオーム（[バイオーム・環境システム](Biome-System.md) 参照）に応じて基本BGMが変化します。
- **洞窟 (Cave)**: 反響感のある暗い雰囲気の電子音楽。
- **森林 (Forest)**: 自然の音や木漏れ日を想起させる、軽やかなエスニック音楽。
- **氷雪 (Ice)**: 冷たく澄んだ、透明感のあるピアノやシンセパッド。
- **溶岩 (Lava)**: 焦燥感を煽る重厚な低音と打楽器中心の曲調。

### 3.3 PK（プレイヤーキラー）介入
ダンジョンにPKer（他プレイヤー憑依モンスター等）が乱入（介入）した場合、BGMは即座に **「PK戦専用BGM（高テンポかつ緊迫感のある戦闘曲）」** に切り替わります（詳細は [PKシステム](PK-System.md) を参照）。
- **遷移トリガー**: PKer が同じ階層に出現した瞬間。
- **復帰トリガー**: PKer を撃退、またはPKerが退散して安全が確保された瞬間、元のバイオームBGMにクロスフェードで復帰。

### 3.4 危機・低ステータス状態（ピンチ演出）
プレイヤーの生命線や生命に危険が及んでいる場合、オーディオ的な演出（ピンチ演出）が重畳されます。
- **低HP状態 (HP 20% 以下)**:
  - BGMに **ローパスフィルター（Low-pass Filter）** が適用され、こもったような音質になります。
  - 同時に、一定の間隔で **心音（鼓動）のSE** が再生され、緊張感を煽ります。
- **飢餓状態 (Starving)**:
  - 満腹度が 0 になり、HP減少が始まっている場合（詳細は [満腹度システム](Hunger-System.md) 参照）、BGMのテンポがわずかに遅くなり、不安定なピッチ（デチューン効果）が弱く付与されます。

## 4. SE（効果音）空間音量減衰と制限
臨場感の向上と耳障りな音の重複（音割れや過大な音量）を防ぐため、効果音の発生源の距離に応じた音量減衰および同時再生の制御を行います。

### 4.1 空間音量減衰 (Spatial Volume Attenuation)
効果音（モンスターの攻撃、トラップの発動、地形の破壊など）がプレイヤーの視界内またはその付近で発生した場合、プレイヤーからの直線距離（マンハッタン距離またはチェビシェフ距離、仕様上はチェビシェフ距離を基準とする）に基づいて、音量が動的に減衰します。

- **計算式**:
  - `距離 (d)` = `max(|dx|, |dy|)`
  - **至近距離 (d <= 2)**: 減衰なし (100% 音量)
  - **通常距離 (3 <= d <= 10)**: 線形減衰 (音量 = `1.0 - (d - 2) * 0.1`)
  - **限界距離 (d > 10)**: 視界限界（11x11マス外）のため、音量は 0%（無音）
- **例外**:
  - プレイヤー自身が引き起こしたアクション（自身の攻撃、被弾、アイテム使用）は、常に減衰なし（100%）で再生されます。

### 4.2 同時再生制限 (Concurrent Playback Limiters)
同一フレームまたは極めて短い時間内（例: 0.1秒以内）に、同一のSE（例: モンスター複数体が同時に同じ攻撃を行った際の攻撃音、トラップが連鎖して発動した音）が大量に発生した場合、音割れや不快感を引き起こす可能性があります。
これを防止するため、**「同一SEの最大同時再生数は 3 個まで」** とする同時再生リミッターを適用します。

- 制限がかかった場合、4つ目以降の同一SEは再生キューから無視（破棄）されます。

## 5. 技術的実装

### 5.1 データ定義
プレイヤー環境設定オブジェクトおよびゲームステート管理における型定義の拡張案です。

```typescript
export interface AudioConfig {
  masterVolume: number; // 0.0 to 1.0
  bgmVolume: number;    // 0.0 to 1.0
  seVolume: number;     // 0.0 to 1.0
}

export interface AudioState {
  currentBgmId: string;
  isLowHpEffectActive: boolean;
  isStarvingEffectActive: boolean;
}
```

### 5.2 主要オーディオアセット一覧
実装時に推奨される効果音とBGMのID定義です。

| アセットID | カテゴリ | 用途・トリガー | 備考 |
| :--- | :--- | :--- | :--- |
| `BGM_TOWN` | BGM | 拠点に滞在している時 | 穏やかな曲調 |
| `BGM_CAVE` | BGM | 洞窟バイオーム探索時 | [バイオームシステム](Biome-System.md) |
| `BGM_FOREST` | BGM | 森林バイオーム探索時 | [バイオームシステム](Biome-System.md) |
| `BGM_ICE` | BGM | 氷雪バイオーム探索時 | [バイオームシステム](Biome-System.md) |
| `BGM_LAVA` | BGM | 溶岩バイオーム探索時 | [バイオームシステム](Biome-System.md) |
| `BGM_PK_INTRUSION` | BGM | PKerが同じフロアに進入した時 | [PKシステム](PK-System.md) |
| `SE_STEP` | SE | プレイヤー移動時 | バイオーム地形依存の足音 |
| `SE_ATTACK_HIT` | SE | 攻撃命中時 | 物理攻撃、クリティカル時変化 |
| `SE_ITEM_USE` | SE | アイテム使用時 | ポーション、巻物など |
| `SE_HEARTBEAT` | SE | HP 20% 以下時の心音 | [自然回復システム](Natural-Recovery-System.md) |
| `SE_TRAP_TRIGGER` | SE | トラップ発動時 | [トラップシステム](Trap-System.md) |
