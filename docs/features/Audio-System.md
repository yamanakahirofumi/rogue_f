# Audio-System

## 1. 概要
オーディオ・BGMシステムは、ゲーム内の没入感を向上させ、プレイヤーの状況や周囲の環境変化、ゲームプレイの緊張感をリアルタイムに音響効果としてフィードバックするための仕組みです。このシステムは、音量の設定管理、エリアや状況に応じた動的なBGMの切り替え、効果音（SE）の空間的な位置に応じた減衰処理、および再生負荷を軽減するための同時再生制限を制御します。

## 2. 音量設定 (Volume Configurations)
プレイヤーはゲーム設定画面から音量を個別に調整でき、これらの設定値はプレイヤーのデータ状態に永続化（保存）されます。

- **主音量 (Master Volume)**:
  - ゲーム全体のマスター音量。すべての音声出力（BGM、SE、ボイス等）の最終出力レベルに対して掛け合わされます。
  - 設定範囲: `0.0` 〜 `1.0` (デフォルト: `0.8`)
- **BGM音量 (BGM Volume)**:
  - 背景音楽の音量。
  - 設定範囲: `0.0` 〜 `1.0` (デフォルト: `0.8`)
- **SE音量 (SE Volume)**:
  - 効果音（移動音、攻撃音、トラップ発動音、アイテム取得音、エモート/スタンプ音など）の音量。
  - 設定範囲: `0.0` 〜 `1.0` (デフォルト: `0.8`)
- **永続化仕様**:
  - 音量設定値は [セーブ・ロードシステム](Save-Load-System.md) において、プレイヤーの状態データ（Player State）の一部として保存されます。ゲーム起動時およびセーブデータロード時に自動で適用されます。

## 3. 動的BGM遷移ロジック (Dynamic BGM Transition Logic)
プレイヤーの現在地や状況に応じて、背景音楽（BGM）が自動的かつ滑らかに切り替わります。

### 3.1 エリアによる遷移 (Area-based Transitions)
- **安全地帯・拠点 (Base/Town)**:
  - [拠点システム](Base-System.md) で定義される拠点エリア（Base Area）にいる間は、平和で穏やかな拠点用BGMが再生されます。
- **ダンジョン探索 (Dungeon Exploration)**:
  - ダンジョンに入場すると、探索用のBGMに遷移します。

### 3.2 バイオームによる遷移 (Biome-specific Transitions)
ダンジョンの階層ごとに設定されたバイオームに応じて、異なる探索BGMが再生されます。
- **洞窟バイオーム (Cave)**: 静寂で不気味な洞窟環境に適したダークアンビエント調のBGM。
- **森林バイオーム (Forest)**: 自然の息吹を感じつつも、油断できない緊張感を持つミステリアスなBGM。
- **氷雪バイオーム (Ice)**: 冷気や静寂、孤独感を想起させる透明感のある澄んだBGM。
- **溶岩バイオーム (Lava)**: 灼熱の地熱と煮えたぎるマグマの熱気、生命の危機を想起させる重低音の効いたBGM。
- ※詳細は [バイオーム・環境システム](Biome-System.md) を参照。

### 3.3 PK介入による遷移 (PK Intervention Theme)
- [PKシステム](PK-System.md) による他のプレイヤーやPKer（侵入者）が同じフロアに介入・侵入した際、探索BGMから即座に**高緊張なバトルテーマ（戦闘BGM）**へと強制的に切り替わります。
- 侵入者が撃破されるか、フロアから離脱、もしくはプレイヤーが安全に退避した時点で、元のバイオーム探索BGMに戻ります。

### 3.4 危険状態による遷移 (Danger States)
プレイヤーの生命危機や致命的な状態変化を、BGMのトーン変化や追加の環境音によって直感的に伝えます。
- **低HP状態 (Low HP Danger)**:
  - プレイヤーの残りHPが最大HPの **20% 未満** に低下した際、BGMのピッチが下がる、またはフィルター処理（ローパスフィルター）が施され、同時に鼓動音（心臓音の効果音）がループ再生されます。
- **飢餓状態 (Starvation State)**:
  - プレイヤーの満腹度（Satiety）が **0** になり、スタミナとHPが持続的に減少し始める極限状態（[満腹度システム](Hunger-System.md)参照）において、お腹の鳴る音などの特殊SEが定期的に鳴り、BGMに焦燥感をあおるノイズ風の効果音が追加されます。

### 3.5 クロスフェード遷移 (Crossfade Transition)
- BGMの切り替えが突発的になりプレイヤーに不快感を与えないよう、すべてのBGM遷移は **1.0秒 〜 2.0秒** のフェードアウト・フェードイン（クロスフェード）を介して行われます。

## 4. SEの空間音響減衰 (SE Spatial Volume Attenuation)
ダンジョン内において、音源（トラップ発動、モンスターの咆咆、攻撃など）の発生座標とプレイヤーの現在座標の距離に応じて、効果音（SE）の音量が動的に減衰します。

- **減衰の計算基準**:
  - プレイヤーの現在座標を $(X_p, Y_p)$、音源の座標を $(X_s, Y_s)$ とし、その直線距離（グリッド距離 $D$）を算出します。
    $$D = \sqrt{(X_p - X_s)^2 + (Y_p - Y_s)^2}$$
- **音量減衰仕様**:
  - **至近距離 ($D \le 2$ タイル)**: 音量は減衰せず、設定されたSE音量の **100%** で再生されます。
  - **中距離 ($2 < D \le 10$ タイル)**: 距離に比例して音量が線形減衰（Linear Attenuation）します。
  - **遠距離 ($D > 10$ タイル)**: プレイヤーの通常の [視界システム](Visibility-System.md)（標準視界範囲内）の限界を超える、または距離が 10 タイルを超えた場合、音量は **0%**（無音）となり、再生自体がスキップされます。
- **パンニング (左右バランス)**:
  - プレイヤーに対する音源の相対方向（左右のX軸の差）に基づき、ステレオ左右の定位（パンニング）が動的に適用されます。これにより、どの方向で音が鳴ったかをプレイヤーが立体的に把握できます。

## 5. 同時再生制限 (Concurrent Playback Limiters)
複数のモンスターの同時攻撃や多重のトラップ発動など、同一フレームまたは極めて短い時間内に同じ効果音が重なって再生されることで発生する、音割れ（クリッピング）やCPU/ブラウザのオーディオ負荷を防止するため、同時再生制限を設けます。

- **再生制限ルール**:
  - **同一効果音の最大同時発音数**: **最大3個** まで。
  - 同一のオーディオアセット（例：`slash_se`、`explosion_se`）がすでに3個同時再生されている状態で、4個目の同じ効果音の再生リクエストが発生した場合、以下のいずれかの処理を行います。
    - 新しい再生を無視する（発音スキップ）。
    - 再生開始から最も時間が経過している古いサウンドを強制終了し、新しいサウンドを再生する（ボイススティーリング - Voice Stealing）。
- **混雑時全体の最大同時発音数 (Voice Limit)**:
  - システム全体で同時に再生できるSEの総数は、負荷軽減のため **最大32音** に制限します。
