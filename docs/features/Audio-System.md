# Audio-System

## 1. 概要
オーディオシステム（Audio System）は、RogueF における BGM（バックグラウンドミュージック）および SE（効果音）の再生、制御、および管理を司る仕組みです。
プレイヤーのゲームプレイへの没入感を高め、戦闘、移動、罠の発動、各種状態変化などのイベントを聴覚的にフィードバックすることで、リアルタイム・ローグライクとしての戦略性と状況判断能力を向上させることを目的としています。

## 2. 音響システムの基本設計と状態管理

### 2.1 クライアント音響管理 (Web Audio API)
本作はモダンブラウザでの動作を基本とするため、音響制御には **Web Audio API** および HTML5 `Audio` 要素を採用します。
- **低遅延再生**: 即時性が求められる効果音 (SE) は Web Audio API の `AudioBuffer` を用いてメモリ上にデコードし、遅延なくトリガーします。
- **ストリーミング再生**: 長尺の BGM は、メモリ節約のため HTML5 `AudioElementAudioSourceNode` を介してストリーミング再生します。

### 2.2 ボリューム設定とデータ永続化
ユーザーは設定画面から、個人の好みに合わせて音量を調整できます。設定値は以下の3つに分かれています。

- **マスター音量 (Master Volume)**: 全体の音量を 0% 〜 100% の範囲で調整します（初期値 80%）。
- **BGM 音量 (BGM Volume)**: バックグラウンドミュージックの音量を 0% 〜 100% の範囲で調整します（初期値 70%）。
- **SE 音量 (SE Volume)**: 効果音の音量を 0% 〜 100% の範囲で調整します（初期値 90%）。

#### 設定データの永続化
これらの音量設定は、[セーブ・ロードシステム](Save-Load-System.md) に基づき、クライアント側の `localStorage` またはサーバー側の `Player` 保存用 JSON スキーマに `AudioConfig` として保持・永続化されます。
```typescript
interface AudioConfig {
  masterVolume: number; // 0.0 ~ 1.0
  bgmVolume: number;    // 0.0 ~ 1.0
  seVolume: number;     // 0.0 ~ 1.0
  isMuted: boolean;     // ミュートフラグ
}
```

## 3. BGM システムと再生・遷移ロジック

状況やエリア、ゲームステートの遷移に応じて、BGM はシームレスかつ動的に切り替わります。

### 3.1 エリア・バイオーム別 BGM 設定
プレイヤーの現在位置に基づいて、再生されるベース BGM が決定されます。

| 滞在場所 | BGMトラック名 | テンポ/調性 | 説明 |
| :--- | :--- | :--- | :--- |
| **拠点 / タウン** | `bgm_town_peace` | 穏やか / 長調 | 安全地帯でのリラックスした雰囲気。 |
| **始まりの洞窟 (洞窟)** | `bgm_dungeon_cave` | 低音重視 / 短調 | [バイオーム・環境システム](Biome-System.md) に対応。暗く静かな洞窟の探検感。 |
| **豊穣の森林 (森林)** | `bgm_dungeon_forest` | 軽快 / 民族調 | [バイオーム・環境システム](Biome-System.md) に対応。生命力にあふれた賑やかな森。 |
| **凍てつく氷原 (氷雪)** | `bgm_dungeon_ice` | 透明感 / 静寂 | [バイオーム・環境システム](Biome-System.md) に対応。静まり返った氷の世界。 |
| **焦熱の火山 (溶岩)** | `bgm_dungeon_lava` | 重厚 / 緊張 | [バイオーム・環境システム](Biome-System.md) に対応。マグマがうごめく危険地帯。 |
| **モンスターハウス** | `bgm_monster_house` | アップテンポ / 激しい | [ダンジョン生成システム](Dungeon-Generation-System.md) のモンスターハウス進入時に再生。 |

### 3.2 動的 BGM 遷移ルール
BGM の切り替えは、急激なカットアウトを避け、ゲームの雰囲気を損なわないように **フェードアウト・フェードイン（クロスフェード）** を用いて実行します。

- **通常遷移**: 通常の階層移動や拠点への帰還時は、移行前の曲を **1.5 秒** かけてフェードアウトさせ、同時に新しい曲を **1.5 秒** かけてフェードインさせます。
- **緊急事態遷移 (PK乱入・ピンチ状態)**: 以下のような高い緊迫度を持つイベントが発生した場合、再生中だったバイオーム BGM は即座にフェードアウト（**0.5 秒**）し、緊急事態用 BGM へ切り替わります。

#### 3.2.1 PK乱入・インターベンション時
- **条件**: [PKシステム](PK-System.md) に基づき、他プレイヤー（PKer）が自身の探索フロアに乱入・進入した瞬間。
- **再生BGM**: `bgm_pk_intervention`（非常に緊迫感のあるハイテンポなチェイス・バトル曲）
- **優先度**: すべてのバイオーム BGM およびモンスターハウス BGM より優先されます。
- **解除**: PKer を撃破するか、あるいは自身が脱出・死亡してフロアから離脱した際、通常のバイオーム BGM または拠点 BGM へフェードで戻ります。

#### 3.2.2 瀕死・飢餓状態 (ピンチ)
- **条件**: プレイヤーの HP が最大 HP の **20% 以下** に低下、または [満腹度システム](Hunger-System.md) による「飢餓 (Starving)」状態に突入した時。
- **再生BGM**: 現在再生中の BGM にローパスフィルタ（音をこもらせる効果）を適用し、心臓の鼓動音 SE (`se_heartbeat`) を 1.0 秒周期でループ再生します。
- **効果**: プレイヤーの生存危機を聴覚的に強く印象づけ、緊張感を極限まで高めます。

## 4. SE（効果音）システムと音量減衰ルール

戦闘、トラップ発動、アイテムの使用など、あらゆる即時的アクションに対して適切な効果音が再生されます。

### 4.1 3D 音響と距離減衰 (Distance Attenuation)
プレイヤー自身の行動や UI 操作に関する効果音は常に 100%（設定された SE 音量）で再生されますが、周囲のモンスターやトラップが引き起こすイベント音については、**プレイヤーからの距離（タイル数）** に応じて音量が動的に減衰します。

- **計算基準**: プレイヤーから音源（イベント発生座標）までのマンハッタン距離または直線距離（$d$）を使用します。
- **減衰ルール**:
  - **$d \le 2$ マス**: 減衰なし（音量倍率 1.0）。隣接または至近距離の戦闘や罠。
  - **$3 \le d \le 10$ マス**: 線形減衰（音量倍率 $= 1.0 - (d - 2) \times 0.1$）。離れるにつれて徐々に音が小さくなります。
  - **$d > 10$ マス**: 完全無音（音量倍率 0.0）。[視界システム](Visibility-System.md) の標準視界範囲外に位置するため、プレイヤーには聞こえません。
- **遮蔽補正**: プレイヤーと音源の間に「壁」が存在する場合、さらに音量倍率を **0.5 倍** に補正し、こもった音質へと変化させます。

### 4.2 同時発音数制限 (Polyphony Limit)
同一の効果音が極めて短い時間内に大量にトリガーされた場合（例：範囲魔法で 10 体のモンスターが同時にダメージを受けた、モンスターハウスで一斉に鳴き声がした等）、音が重なり合って大音量になり、プレイヤーの聴覚に悪影響を与えるのを防ぐため、以下の同時発音数制限（ボイスリミット）を設けます。

- **同一 SE の最大同時再生数**: **3 ボイス** まで。
- **制御ロジック**:
  - 同一 SE が同時に（または 0.05 秒以内の間隔で）トリガーされた場合、すでに再生中の同一 SE の音量を検出します。
  - 4 個目以降のトリガー要求は、最も再生が進んでいる（あるいは音量が小さい）既存ボイスをカットするか、トリガー自体を無視（破棄）します。

## 5. アセット仕様と仕様要件

### 5.1 オーディオファイル形式
web アプリケーションのロード速度、圧縮効率、および互換性を考慮し、以下の形式を必須とします。
- **メイン形式**: `.ogg` (Ogg Vorbis) - 高音質かつループ情報の埋め込みが可能であり、Chrome などのモダンブラウザに最適です。
- **フォールバック形式**: `.mp3` - ほぼ全ての Web プラットフォームでデコード可能。

### 5.2 シームレスループ処理 (Seamless Loop)
BGM を途切れなくループさせるため、オーディオアセット自体にループポイント（サンプル単位の開始・終了指定）を埋め込むか、Web Audio API の `AudioBufferSourceNode` の `loopStart` および `loopEnd` プロパティを活用して、フレーム単位で正確なシームレス再生を実装します。
