# Statue-System

## 1. 概要
彫像システム（Statue System）は、ダンジョン管理者（Administrator）が「マイ・ダンジョン」に設置可能な「彫像（`statue`）」に特殊効果を付与し、ダンジョンの防衛戦略や環境補正をカスタマイズするための仕組みです。
これまで「装飾」目的のみに留まっていた彫像に具体的な機能を持たせ、特定の範囲内のエンティティ（プレイヤー、モンスター）に対してバフ・デバフ効果を与えることができます。

## 2. 彫像の種類と特殊効果
管理者は設置した彫像（`statue`）に対して、以下の 5 種類の特殊効果（種類）から 1 つを任意に選択・設定することができます。

### 2.1 畏怖の彫像 (`dread`)
- **対象**: 侵入者（Explorer、PKer 派閥）
- **効果**: 彫像の有効範囲内にいるすべての侵入者の攻撃命中率を **10% 減少（0.9 倍）** させる。
- **用途**: 攻撃力の高いプレイヤーや乱入者を弱体化させ、防衛モンスターの生存率を高める。

### 2.2 守護の彫像 (`guardian`)
- **対象**: 管理者モンスター（Admin 派閥）
- **効果**: 彫像の有効範囲内にいるすべての味方モンスターの防御力を **15% 上昇（1.15 倍）** させる。
- **用途**: 耐久力の高いモンスターやボスと組み合わせることで、強固な防衛線を構築する。

### 2.3 癒やしの彫像 (`healing`)
- **対象**: 管理者モンスター（Admin 派閥）
- **効果**: 10 秒周期（メインティック）ごとに、有効範囲内にいるすべての味方モンスターの HP およびスタミナ（ST）を **2 ポイント** 自然回復させる。
- **用途**: 防衛用モンスターのスタミナ切れを防ぎ、戦闘力を維持し続ける。

### 2.4 強欲の彫像 (`greed`)
- **対象**: 侵入者（Explorer、PKer 派閥）を撃破した際
- **効果**: 彫像の有効範囲内で侵入者が撃破された際、管理者が獲得する経験値およびゴールドを **1.2 倍** に増加させ、追加のアイテムドロップ率を **+5%** 上昇させる。
- **用途**: 罠（トラップ）や精鋭モンスターを集中配置した「キルゾーン」に設置し、リソースの回収効率を最大化する。

### 2.5 輝きの彫像 (`glow`)
- **対象**: 範囲内のタイルおよび侵入者
- **効果**: 周囲を明るく照らす（標準で半径 5 マス）。また、有効範囲内の侵入者の「探索（`search`）」および「解除（`disarm`）」の成功率を **20% 減少（0.8 倍）** させる。
- **用途**: 視界を確保すると同時に、罠を密集させたエリアでのトラップ発見・解除を妨害する。

## 3. 有効範囲と適用ルール

### 3.1 範囲の判定 (Chebyshev Distance)
彫像の効果が適用される範囲は、以下の基準に従います。
- **部屋内（Room-wide）**: 彫像が「部屋」の内部に配置されている場合、その部屋の床（`.`）タイル全体を有効範囲とします。
- **通路・開けた場所（Local-range）**: 彫像が通路や境界のない場所に配置されている場合、彫像の位置を中心とした **チェビシェフ距離で 2 マス以内（5x5 タイルの範囲）** を有効範囲とします。

### 3.2 派閥による適用フィルタリング
各彫像の効果は、エンティティの「派閥（Faction）」に基づいて自動的にフィルタリングされます。
- 味方モンスター（管理者派閥）のみにバフを適用し、侵入者（Explorer、PKer 派閥）にのみデバフを適用することで、不当な不利益を避ける設計となっています。詳細は **[派閥システム](Faction-System.md)** を参照してください。

### 3.3 重複時の挙動
同じ種類の彫像の効果範囲が重複した場合、その効果は**累積（スタック）しません**（常に最も高い効果が 1 つだけ適用されます）。異なる種類の彫像の効果（例：守護の彫像と癒やしの彫像）は同時に重複して効果を発揮します。

## 4. 設置・設定方法

### 4.1 コストと容量
- **設置コスト**: `stone`（石材） × 10, 800 ゴールド
- **消費容量**: **5 容量**
- 詳細は **[施設マスターリスト](Facility-Master-List.md)** および **[建築システム](Construction-System.md)** を参照してください。

### 4.2 設定データ
設置された彫像の設定は、`PlacedFacility` モデル内の `StatueConfig` で管理されます。
```typescript
interface StatueConfig {
  effectType: 'dread' | 'guardian' | 'healing' | 'greed' | 'glow'; // 彫像の特殊効果
}
```
