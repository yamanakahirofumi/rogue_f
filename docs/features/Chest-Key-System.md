# Chest-Key-System

## 1. 概要
宝箱・鍵システムは、ダンジョン探索におけるリスクとリターンの緊張感を高め、プレイヤーに「インベントリ管理の葛藤」と「選択の楽しみ」を提供する仕組みです。
ダンジョン内には様々な種類の宝箱が配置され、それらを開けるための専用の鍵や、特定の開錠スキル（器用さや運に依存）、物理的な破壊手段が必要となります。

## 2. 宝箱の基本仕様

### 2.1 宝箱の種類と特性
出現する宝箱は、以下の 4 つのタイプに分類されます。

| 宝箱タイプ | 必要アイテム/手段 | 報酬 Tier | 破壊耐性 | ミミック化確率 | 備考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **木箱 (Wooden Chest)** | なし（直接開封可能） | Tier 1 〜 2 | 低（100% 成功） | 1% | 一般的な箱。攻撃で簡単に壊せる。 |
| **鉄の宝箱 (Locked Iron Chest)** | `key_iron` (鉄の鍵) / 開錠 | Tier 2 〜 3 | 中（ATK 20以上） | 5% | 施錠されている。強力な装備や薬が含まれる。 |
| **魔力の宝箱 (Locked Magic Chest)** | `key_magic` (魔力の鍵) | Tier 3 | 高（破壊不可） | 0% | 魔法障壁で守られた最高級の宝箱。 |
| **ミミック (Mimic)** | 接触 / 攻撃 / 開錠試行 | なし（戦闘開始） | - | - | 宝箱に擬態したモンスター。[モンスターマスターリスト](Monster-Master-List.md)参照。 |

### 2.2 配置ルール
- **出現率**: 各フロアの部屋内に、1 部屋あたり 5% 〜 15% の確率で配置されます（深層ほど「鉄の宝箱」や「魔力の宝箱」の比率が増加）。
- **特殊部屋での配置**: [ダンジョン生成システム](Dungeon-Generation-System.md)に定義される「宝物庫 (Treasure Room)」や「モンスターハウス」には、必ず 1 つ以上の「鉄の宝箱」または「魔力の宝箱」が確定配置されます。

## 3. 鍵と開錠のメカニズム

### 3.1 鍵アイテム
開錠に必要な鍵は、以下の 2 種類が存在します。各アイテムの詳細は**[アイテムマスターリスト](Item-Master-List.md)**を参照してください。
- **`key_iron` (鉄の鍵)**: 鉄の宝箱を開けるための標準的な鍵。
- **`key_magic` (魔力の鍵)**: 魔力の宝箱を開けるための特殊な鍵。

### 3.2 アクションと開錠手段
宝箱に対して隣接した状態で、以下の 3 つのアプローチを選択できます。

#### 3.2.1 鍵を使用する (Use Key)
- 最も安全な開錠方法です。
- 対応する鍵アイテムをインベントリから消費することで、100% の確率で安全に宝箱を開け、中身を獲得できます。

#### 3.2.2 鍵開けを試みる (Lockpick)
- 鍵を持っていない場合、プレイヤーの「器用さ (dexterity)」と「運 (luck)」に基づき、手動での開錠（ピッキング）を試みることができます。
- **開錠難易度**: 木箱=10、鉄の宝箱=50（※魔力の宝箱はピッキング不可）。
- **開錠成功率計算式 (%)**:
  `開錠成功率(%) = ((器用さ * 1.5 + 運) / 開錠難易度) * 100`
  - ※上限は 90%、下限は 5% とします。
- **失敗時のリスク**:
  ピッキングに失敗した場合、以下のいずれかのペナルティがランダム（等確率）で発生します。
  1. **鍵詰まり (Locked Jam)**: 鍵穴が壊れ、以降ピッキングによる開錠が完全に不可能になります（「物理的破壊」のみ可能）。
  2. **罠の発動 (Trap Trigger)**: 宝箱に仕掛けられたトラップ（毒針、矢、爆発など）が発動し、プレイヤーがダメージまたは状態異常を受けます。
  3. **ミミックの覚醒 (Mimic Wakeup)**: 宝箱がミミック（擬態中だった場合）に変貌し、即座に先制攻撃を行ってきます。

#### 3.2.3 物理的に破壊する (Smash / Attack)
- 武器による物理攻撃によって宝箱を強引にこじ開けます。
- **破壊成功率**:
  - **木箱**: 100%（攻撃するだけで即座に開く）
  - **鉄の宝箱**: プレイヤーの攻撃力（ATK）が 20 以上の場合のみ 50% の確率で成功。20 未満の場合は「刃が立たない」と表示され失敗します。
  - **魔力の宝箱**: 物理破壊は一切不可能です。
- **アイテム破損のリスク**:
  物理的破壊に成功した場合、衝撃によって中のアイテムが破損するリスクが伴います。
  - **木箱の破損率**: 30%
  - **鉄の宝箱の破損率**: 80%
  - **破損時の挙動**: 獲得できるはずだったアイテムが、**「木材 (`wood`)」** または **「腐った食料 (`rotten_food`)」** に変化します。

## 4. ミミック（擬態）との判別方法
一部の宝箱は、[モンスターマスターリスト](Monster-Master-List.md)に記載された「ミミック (`mimic`)」が擬態したものです。

### 4.1 判別メカニズム
プレイヤーは以下の手段で、安全に本物の宝箱とミミックを判別することができます。
- **探索アクション (Search)**:
  - 隣接した状態で「探索」アクションを行うことで、ミミックの擬態を見破ることができます。
  - **見破り成功率**: `((器用さ * 2 + 運) / 40) * 100` (%)
  - 見破りに成功した場合、マップ上の表示が「宝箱」から「モンスター（ミミック）」に変化し、先制攻撃を防ぐことができます。
- **投擲 (Throwing)**:
  - 離れた位置からアイテム（石、不要な装備など）を宝箱にぶつけることで、ミミックであった場合は擬態が解除され、戦闘状態へ遷移します。

## 5. データ構造と関連フィールド
宝箱の動的状態および開錠処理結果は、以下のモデルおよび [Player型定義](../../src/@types/player.d.ts) のインターフェースに基づいてフロントエンド・バックエンド間でやり取りされます。

- **`ChestType`**: `'wood' | 'iron' | 'magic' | 'mimic'`
- **`ChestOpenResult`**: 開錠試行時のレスポンスモデル（詳細は [Player型定義](../../src/@types/player.d.ts) を参照）。
