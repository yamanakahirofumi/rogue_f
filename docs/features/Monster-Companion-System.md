# Monster-Companion-System

## 1. 概要
モンスター同行（オトモコンパニオン）システムは、探索者（Explorer）が拠点や倉庫で所有・育成しているモンスターから 1 体を選び、「同行仲間（オトモ）」としてダンジョン探索へ連れて行くことができる仕組みです。
単独でのダンジョン攻略に加え、仲間モンスターとの連携攻撃、各種サポートスキル、タンク役としての囮プレイなど、多角的な戦略性を探索者に提供します。

## 2. 同行モンスターの選定と出撃ルール

### 2.1 出撃条件
- **所持上限**: ダンジョン内に同時に同行（出撃）できるモンスターは **1 体のみ** です。
- **対象モンスター**: 拠点倉庫（[倉庫システム](Warehouse-System.md)）に保管されている、状態が `'idle'` の所持モンスターから選択できます。
- **成長段階要件**: 「成体」（レベル 5 以上）に成長しているモンスターのみ同行可能です。生まれたばかりの「幼体」（レベル 1 〜 4）は同行できません（[モンスターシステム](Monster-System.md#4-2-1-モンスターの成長段階-growth-stages) 参照）。
- **出撃コスト（活力消費）**: 出撃時に対象モンスターの **活力 (Vigor) を 30 消費** します。残活力が 30 未満のモンスターは同行出撃させることができません。

### 2.2 ステータスと成長
- **能力引き継ぎ**: 倉庫内の個別ステータス（HP、スタミナ、攻撃力、防御力、敏捷性、器用さ、素早さ、運、所持スキル、継承特性）がそのまま同行状態に引き継がれます。
- **経験値とレベルアップ**: 同行中に敵モンスターを撃破した場合、探索者と同行モンスターの双方が経験値を獲得します。獲得経験値の計算は [経験値・レベルアップシステム](Leveling-System.md) の標準計算式に準拠し、同行モンスターのレベルアップ時には AI パターンに基づいたステータス成長（[モンスターシステム](Monster-System.md#4-2-育成成長システム) 参照）が即座に反映されます。

## 3. AI作戦（タクティクス）切り替え

探索者は、探索状況や戦闘スタイルに応じて同行モンスターの AI 戦闘方針（作戦）をリアルタイムに切り替えることができます。

### 3.1 作戦（Tactics）マスター一覧

| 作戦 ID | 名称 | 行動方針 | AI ターゲット選択ロジック |
| :--- | :--- | :--- | :--- |
| `aggressive` | **積極攻撃** | 視界内の敵に対して最も積極的にアプローチし、スキルや攻撃を集中させます。 | 視界内で最も距離が近い敵、または最も HP が低い敵を優先ターゲットとします。 |
| `defensive` | **防御・護衛** | 探索者の周囲 2 マス以内を維持し、探索者を狙う敵を優先的に引きつけます。 | 探索者を攻撃した敵、または探索者に最も近接している敵をターゲットとします。 |
| `support` | **支援・回復** | 探索者や自身の HP が低下した際、所有する回復・バフスキルを優先的に使用します。 | 敵への攻撃よりも、探索者の HP が 50% 未満時の回復・補助スキル発動を最優先します。 |
| `follow` | **追従優先** | 敵への攻撃を行わず、探索者の後を忠実に追従します。狭い通路での交戦回避や退避時に有効です。 | 探索者との距離を 1 〜 2 マスに維持するように移動のみを行います。 |

### 3.2 作戦変更の実行
- 探索者は探索中、いつでも UI 上のコンパニオンパレット（`CompanionHudWidgetComponent`）または REST API (`PUT /api/player/{userId}/companion/tactic`) を呼び出すことで作戦を変更できます。
- 作戦変更アクションの基本インターバルは **0.2 秒**、消費スタミナは **0 ST** です。

## 4. リソース管理と満腹度・活力

同行モンスターは探索中、独自のリソース管理（満腹度・活力）が必要となります。

### 4.1 満腹度 (Satiety) と給餌 (Feeding)
- **最大満腹度**: 全モンスター共通で **100** です。
- **満腹度の減少**: 同行モンスターが 1 回のアクション（移動・攻撃・スキル使用）を実行するごとに、満腹度が **0.1** 減少します。
- **飢餓状態 (Starving)**: 満腹度が 0 になると「飢餓」状態となり、10 秒（1 ティック）ごとに最大 HP の 2% のスリップダメージが発生し、自然回復が完全停止します。
- **給餌 (Feed)**: 探索者はインベントリ内の食料アイテム（肉、魚、パン等）を同行モンスターに与えることで満腹度および HP を回復させることができます (`POST /api/player/{userId}/companion/feed`)。
  - 食料を与えた際、アイテムのカテゴリや品質に応じて満腹度が回復し、`CompanionFeedResult` レスポンスが返却されます。

### 4.2 活力 (Vigor) と帰還
- 出撃時に 30 消費された活力は、同行中には時間経過で減少しません。
- ただし、後述の「転倒・ロスト」発生時や、手動で同行を解除（帰還）させた際には残活力が保持された状態で倉庫へ復帰します。

## 5. 転倒（Downed）と死亡・帰還メカニズム

同行モンスターの HP が 0 になった際の救済および帰還ルールです。

### 5.1 転倒（Downed）状態
- **発動条件**: 同行モンスターの HP が 0 に達した際、即座にロスト（即死）するのではなく、その場で**「転倒 (Downed)」状態**となります。
- **行動制限**: 転倒中のモンスターは移動・攻撃・スキル発動が一切不能となり、その場に倒れ込みます。
- **救済タイムリミット**: 転倒状態は **30 ティック（約300秒 / 5分）** 継続します。

### 5.2 蘇生 (Revive) と回収 (Dismiss / Death)
- **蘇生**: 探索者が転倒タイマー内（30 ティック以内）に「気付け薬」や「蘇生草」、または回復魔法・アイテムを使用することで、HP 30% の状態で現場復帰・戦線復帰させることができます。
- **時間切れによる自動送還**: 30 ティック以内に蘇生されなかった場合、または探索者が同行モンスターを置いたまま別階層へ移動した場合、同行モンスターは**活力 (Vigor) が 0 の状態**となり、拠点倉庫へ強制転送・送還されます。
- **手動帰還 (`dismiss`)**: 探索者は非戦闘時（周囲 5 マス以内に敵がいない状態）に手動で同行モンスターを拠点へ帰還させることができます。手動帰還時は残活力を維持したまま倉庫へ復帰します。

## 6. UI/UX と操作フィードバック

### 6.1 コンパニオン HUD ウィジェット (`CompanionHudWidgetComponent`)
画面左上（プレイヤー基本ステータスバーの下部）に配置され、以下の情報をリアルタイムに表示します。
- **モンスターアイコン & 名前**: 種別スプライトおよび個別名（Level 表示付き）。
- **HP / ST / 満腹度バー**: グリーン（HP）、イエロー（ST）、オレンジ（満腹度）のプログレスバー。
- **現在の作戦バッジ**: `aggressive` (赤), `defensive` (青), `support` (緑), `follow` (黄) のタグアイコン。
- **転倒警告タイマー**: 転倒発生時、赤色点滅と共に残り 30 ティックのカウントダウンを表示。

### 6.2 給餌・作戦切り替えパレット
ウィジェットをクリックまたはショートカットキー入力することでポップアップし、所持食料の一覧からの給餌操作、および 4 種の作戦ボタンの即時切り替えが可能です。

## 7. REST API 仕様

### 7.1 同行出撃 (`POST /api/player/{userId}/companion/deploy`)
- **概要**: 倉庫内の指定モンスター（'idle' 状態、活力 30 以上）を同行出撃させます。
- **リクエスト**: `CompanionDeployRequest` (`{ monsterId: string }`)
- **レスポンス**: `CompanionDeployResult`

### 7.2 同行解除・帰還 (`DELETE /api/player/{userId}/companion/dismiss`)
- **概要**: 現在同行中のモンスターを安全に拠点倉庫へ手動帰還させます。
- **レスポンス**: `CompanionDismissResult`

### 7.3 AI作戦更新 (`PUT /api/player/{userId}/companion/tactic`)
- **概要**: 同行モンスターの AI 作戦方針（`aggressive`, `defensive`, `support`, `follow`）を更新します。
- **リクエスト**: `CompanionTacticUpdateRequest` (`{ tactic: 'aggressive' | 'defensive' | 'support' | 'follow' }`)
- **レスポンス**: `CompanionTacticUpdateResult`

### 7.4 給餌 (`POST /api/player/{userId}/companion/feed`)
- **概要**: インベントリ内の食料アイテムを指定して同行モンスターに与え、満腹度と HP を回復させます。
- **リクエスト**: `CompanionFeedRequest` (`{ foodItemId: string }`)
- **レスポンス**: `CompanionFeedResult`
