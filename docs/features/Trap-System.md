# Trap-System

## 1. 概要
トラップシステムは、ダンジョン内に設置された罠によってプレイヤーの探索を妨害し、緊張感と戦略性を与える仕組みです。管理者は自身のダンジョンにトラップを戦略的に配置することで、侵入者に対する防衛力を高めることができます。

## 2. トラップの種類
トラップはその効果に応じていくつかのカテゴリに分類されます。

### 2.1 ダメージ系トラップ
プレイヤーのHPを直接減少させます。ダメージ計算は以下の式をベースに行われます。

`最終ダメージ = ((トラップの基本威力) - (防御力 / 2)) * 属性倍率`

- **防御力の影響**: 物理的なトラップだけでなく、属性を持つトラップに対してもプレイヤーの防御力の半分（切り捨て）が減算されます。
- **属性倍率の適用**: 属性相性による倍率は、防御力による減算が行われた後の値に対して適用されます。詳細は **[属性システム](Attribute-System.md)** を参照してください。
- **最小ダメージ**: 計算結果が 1 未満になる場合でも、トラップが発動した際は最低 **1** のダメージを受けます。

- **トゲの床 (Spikes)**: 踏むとダメージを受ける。属性は「無」。
- **地雷 (Landmine)**: 踏むと爆発し、自身と周囲にダメージを与える。属性は「火」。

### 2.2 状態異常系トラップ
プレイヤーに一時的な弱体化を与えます。詳細は [状態異常システム](Status-Effect-System.md) を参照してください。
- **毒矢 (Poison Needle)**: 踏むと「毒」状態になる。
- **警報 (Alarm)**: 踏むと大きな音が鳴り、**半径 10 マス以内**のモンスターがプレイヤーを追尾（ターゲット）するようになる。この追尾効果は、対象モンスターがプレイヤーを直接視認していない場合でも適用されます。また、確率で「スタン」状態を引き起こす。
- **鈍足の罠 (Slow Trap)**: 踏むと「鈍足」状態になる。
- **混乱の罠 (Confusion Trap)**: 踏むと「混乱」状態になる。
- **盲目の罠 (Blindness Trap)**: 踏むと「盲目」状態になる。

### 2.3 ユーティリティ系トラップ
プレイヤーの位置やリソースに干渉します。
- **ワープの罠 (Teleport Trap)**: 同じ階層のランダムな座標に転送される。
- **召喚の罠 (Summon Trap)**: 周囲にモンスターを召喚する。
- **装備外しの罠 (Equipment Remover)**: 踏むと、装備している装備品が強制的に解除されます。
    - **解除の優先順位**: 武器 ＞ 防具 ＞ 装飾品
    - **呪いへの対応**: [アイテム識別システム](Item-Identification-System.md) に基づき、**呪われたアイテムはこの罠によって外れることはありません。**
    - **スキップの挙動**: 優先順位の高いスロットが呪われている、または何も装備していない場合は、次の優先順位のスロットが解除の対象となります。全てのスロットが呪われているか未装備の場合、罠は発動しますが実質的な効果（装備解除）はありません。

## 3. 発見と解除

### 3.1 隠れた状態 (Hidden State)
- ほとんどのトラップは、設置された時点ではプレイヤーから見えない「隠れた状態」になっています。
- **発動条件**: トラップの上をエンティティが歩く、または「解除」に失敗した際に発動します。
- **ターゲットの制限**:
    - **野生のトラップ (Wild Traps)**: ランダムダンジョン（フロンティア）に初期配置されているトラップは、**全てのエンティティ（プレイヤー、モンスター、PKer）** に対して反応し、発動します。
    - **管理者設置のトラップ (Admin-placed Traps)**: 管理者が「マイ・ダンジョン」に設置したトラップは、**侵入者（プレイヤーおよび PKer）に対してのみ**反応し、発動します。管理者が配置した NPC モンスターがトラップの上を歩いても、トラップが発動することはありません。
- **使い捨て (One-time Use)**: 一度発動したトラップは、その効果を発揮した後、設置主体に関わらず **フィールド上から消滅** します。

### 3.2 探索 (Search)
- プレイヤーは周囲を「探索」するアクションを行うことで、隠れたトラップを発見できる可能性があります。
- **発見確率計算式 (%)**:
    - `発見確率(%) = ((器用さ * 2 + 運) / (トラップの難易度 * 0.5)) * 100`
    - ※上限は 100%、下限は 5% とします。
- 運（Luck）や特定のステータス、または「明かりの巻物」などのアイテムを使用することで、トラップを可視化できます。

### 3.3 解除 (Disarming)
- 発見されたトラップに対して、隣接した状態で「解除」を試みることができます。
- **解除成功率計算式 (%)**:
    - `解除成功率(%) = ((器用さ * 3 + 運) / トラップの難易度) * 100`
    - ※上限は 100%、下限は 10% とします。
- 解除に失敗すると、その場でトラップが発動するリスクがあります。

## 4. 管理者による配置

### 4.1 「マイ・ダンジョン」での運用
- 管理者は、自身が運営するダンジョンにおいて、所持している「トラップ資材」やゴールドを消費してトラップを配置できます。
- モンスターの配置（[モンスターシステム](Monster-System.md)）と組み合わせることで、より強力な防衛網を構築できます。
  - 例: 鈍足の罠の周囲に、遠距離攻撃を持つモンスターを配置する。

### 4.2 配置制限
- 1 つの部屋や階層に配置できるトラップの総数には、ダンジョンのレベルに応じた上限があります。
- 階段の直上など、プレイヤーが回避不能な場所への配置には制限がかかる場合があります。
