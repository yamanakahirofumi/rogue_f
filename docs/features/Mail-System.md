# Mail-System

## 1. 概要
メール・プレゼントシステム（Mail & Present System）は、拠点（Base / Town）に設置された「郵便受け（Mailbox）」を通じて、運営やシステムからの通知、ランキング報酬、ダンジョン内での溢れ戦利品、および各種プレゼントメッセージを受信・受領するための仕組みです。

プレイヤーは安全地帯である拠点で郵便受けを開くことで、メッセージの閲覧、添付アイテム（ゴールド、資材、装備、モンスターの卵など）の一括・個別受取、および不要メールの削除を行うことができます。

## 2. メール種別と受取ルール

### 2.1 メールのカテゴリ分類
受信箱に届くメールは、その発信元や目的に応じて以下の4つのカテゴリに分類されます。

1. **システムメール (`system`)**: メンテナンス通知、不具合補填、運営からのアナウンスメント。
2. **ランキング報酬メール (`ranking`)**: 各シーズン終了時に成績に応じて付与される報酬メール（詳細は **[ランキングシステム](Ranking-System.md)** を参照）。
3. **ダンジョン溢れ戦利品 (`dungeon_overflow`)**: ダンジョン攻略・脱出時にインベントリ上限を超過して直接持ち帰れなかった特定報酬やドロップ品。
4. **ギフト・プレゼント (`gift`)**: ログインボーナス、クエスト達成記念、イベント配布アイテム。

### 2.2 受信箱の容量制限と保存期間
- **受信箱の最大容量**: **50通**。上限を超過した場合、古い未保護（未ピン留め）の開封済みメールから自動的に削除されます。
- **有効期限（自動削除）**: メール送信から **30日間**。有効期限を過ぎたメールは、添付アイテムの受取有無に関わらず自動削除されるため注意が必要です。

## 3. 添付アイテム受取と倉庫転送ロジック

### 3.1 受取モード
- **個別受取 (`claim`)**: 選択した1通のメールに添付されたアイテムやゴールドを受領します。
- **一括受取 (`claim-all`)**: 未受取の添付アイテムが存在する全てのメールから、受取可能なアイテムを一括受領します。

### 3.2 インベントリ超過時の倉庫自動転送
添付アイテムを受領する際、プレイヤーのインベントリ（所持枠: 最大20枠）の空き容量が不足している場合、以下の自動転送ロジックが適用されます。

1. **ゴールド**: プレイヤーの所持金（`gold`）に直接加算されます（インベントリ枠は消費しません）。
2. **アイテム・資材・卵**:
   - インベントリ枠に空きがある場合は、優先してインベントリへ格納されます。
   - **インベントリが満床（20/20）の場合**: 溢れたアイテムはプレイヤーの **[倉庫システム](Warehouse-System.md)** へ自動的に転送・格納されます。
   - 倉庫も満床の場合は、受取処理がエラーとなり、メール内に添付アイテムが保持されます。

## 4. データ構造とAPI設計

### 4.1 型定義（TypeScript）
型定義は `src/@types/player.d.ts` 配下に宣言されています。

- **`MailAttachment`**: 添付品の情報（Gold、アイテム種別、数量、詳細パラメータ）。
- **`MailMessage`**: メール本文、送信者、カテゴリ、既読・受取フラグ、送信日時・有効期限。
- **`MailClaimResult`**: 受取結果（獲得ゴールド、獲得アイテム一覧、倉庫への自動転送数）。

### 4.2 REST API エンドポイント
バックエンドAPIの詳細は **[実装詳細](../implementation/Implementation-Details.md)** を参照してください。

- `GET /api/player/{userId}/mail`: メール一覧を取得。
- `POST /api/player/{userId}/mail/{mailId}/claim`: 指定メールの添付品を受取。
- `POST /api/player/{userId}/mail/claim-all`: 全未受取メールの添付品を一括受取。
- `DELETE /api/player/{userId}/mail/{mailId}`: 指定メールを削除。
- `DELETE /api/player/{userId}/mail/clear-read`: 既読・受取済みメールを一括削除。

## 5. UI/UX設計

拠点画面のUIコンポーネントにおける郵便受けの仕様方針は以下の通りです。

- **未読バッジ通知**: 拠点の「郵便受け」アイコン上に未読または未受取添付が存在する通数を赤色バッジで表示。
- **カテゴリフィルタータブ**: 「すべて」「システム」「ランキング」「戦利品」「ギフト」でメール一覧を絞り込み可能。
- **一括操作ボタン**: 「一括受取（Claim All）」および「既読削除（Clear Read）」ボタンを画面下部に配置。
- **詳細ダイアログ**: メール選択時にモーダル表示され、差出人、本文、添付品一覧、受け取りボタンを表示。
