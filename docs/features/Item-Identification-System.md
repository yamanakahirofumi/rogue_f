# Item-Identification-System

## 1. 概要
アイテム識別システムは、プレイヤーがダンジョン内で入手したアイテムの真の正体や付加状態（呪い・祝福）を判明させるための仕組みです。未識別のアイテムを扱う際のリスクと、正体が判明した際の喜びを提供し、探索の戦略性を高めます。

## 2. アイテムの状態
全てのアイテムは、以下の「識別状態」と「付加状態」の組み合わせを持ちます。

### 2.1 識別状態
- **未識別 (Unidentified)**: アイテムの本来の名称や効果が隠されている状態。
  - 表示例: 「謎の薬」、「青い巻物」、「鉄の剣（未識別）」
- **識別済み (Identified)**: アイテムの真の名称と効果が判明している状態。

### 2.2 付加状態 (Status)
アイテム（主に装備品や一部の道具）には、以下の付加状態が存在する場合があります。
- **通常 (Normal)**: 特殊な補正がない標準的な状態。
- **祝福 (Blessed)**: アイテムの効果が強化されている、または特殊な恩恵がある状態。
- **呪い (Cursed)**: 装備すると外せなくなる、または負の効果が発生する状態。

## 3. 識別・鑑定の方法
未識別のアイテムを識別するには、以下の方法があります。

### 3.0 識別の有効範囲 (Identification Scope)
- **種類単位の識別**: アイテンの識別は、そのプレイヤーの現在のセッション（探索中）において**種類単位（Appearance/Type）**で行われます。
  - 例：一度「青い薬」を飲んで「弟切草の薬」だと判明した場合、以降その探索中に入手する全ての「青い薬」は、入手した瞬間から「弟切草の薬（識別済み）」として扱われます。
- **外見のランダム化**: 「未識別時の名称（例：薬の色、巻物の表題）」と「実際のアイテム種別」の対応関係は、**ワールド（サーバー）のセッションまたはリセットごとにランダムに決定**されます。
  - これにより、前回のプレイで「青い薬」が回復薬だったとしても、次のプレイでは毒薬である可能性があるというローグライク性を担保します。

### 3.1 アイテムの使用 (Use)
- 薬や巻物などの消耗品は、実際に使用（飲む、読む等）することでその効果が発揮され、同時に識別済み状態になります。詳細は **[アイテムマスターリスト](Item-Master-List.md)** の「識別方法」を参照してください。
- ただし、マイナスの効果を持つアイテムを識別目的で使用するリスクが伴います。
- **資材とゴールドの扱い**: **資材 (`material`)** および **ゴールド (`gold`)** は、入手した時点で常に「識別済み」として扱われます。

### 3.2 装備 (Equip)
- 武器、防具、および**装飾品（指輪、ペンダント等）**は、装備することでその性能や呪いの有無が判明します。
- 呪われていた場合、特定の手段（解呪の巻物等）を用いない限り、その装備を外すことができなくなります。

### 3.3 鑑定用アイテムの使用
- 「鑑定の巻物」などの専用アイテムを使用することで、インベントリ内の未識別アイテムを安全に識別できます。

### 3.4 店での鑑定
- ダンジョン内のショップにおいて、店主に有料で鑑定を依頼できます。
- **鑑定料**: アイテムの基本価格（[アイテムマスターリスト](Item-Master-List.md) の `value`）の **20%**。
  - 基本価格（Base Price）に基づき算出され、市場価格（Market Price）の変動の影響を受けません。
  - **価格の基準**: 鑑定料の基準となる基本価格は、対象のアイテム種別が持つ**標準（Normal）状態の価格**を用います。呪いや祝福による補正がかかる前の値が適用されます。
  - ※小数点以下は**切り捨て**。
  - ただし、最低鑑定料を **50 ゴールド** とします。

### 3.5 投擲（着弾）による識別
- 薬（Potions）などの一部の消耗品は、投擲によってエンティティや壁に着弾した際、その効果が発揮（拡散）されることで識別済み状態になります。
- **識別の条件**: 投擲による識別は、以下の条件を共に満たした場合にのみ成立します。
    - アイテムの効果（状態変化、ダメージ等）が、対象となるエンティティや地形に対して実際に発揮されたこと。
    - その効果の発生が、プレイヤー（探索者）の現在の視界（Visibility）の範囲内で観測されたこと。
- 詳細は **[戦闘システム](Combat-System.md#3-1-投擲の基本仕様)** を参照してください。

## 4. 呪いと祝福のメカニズム

### 4.1 呪いの影響
- **装備の固定**: 呪われた武器や防具を装備すると、通常の操作では変更・解除ができなくなります。
- **性能低下**: 攻撃力や防御力にマイナス補正（一律 **-1**）がかかります。
- **消耗品（薬・食料）の弱体化**: 回復量や効果時間が本来の **0.5 倍**（小数点以下切り捨て、最低 1）に低下します。
- **巻物の不発**: 呪われた巻物は、使用時に **50%** の確率で効果が発動せずに消滅します。
- **特殊効果の阻害**: 本来の効果が発動しなくなる場合があります。

### 4.2 祝福の恩恵
- **性能向上**: 攻撃力や防御力にプラス補正（一律 **+1**）がかかります。
- **消耗品（薬・食料）の強化**: 回復量や効果時間が本来の **1.5 倍**（小数点以下切り捨て）に向上します。
- **巻物の消費抑制**: 祝福された巻物は、使用時に **25%** の確率で消費されずに手元に残ります。
- **消費の抑制**: 効果時間が延長される場合があります。

## 5. データモデルとの関連
本システムの状態は、`InventoryItem` インターフェースの以下のプロパティで管理されます。

- `isIdentified`: 識別状態（true=識別済み, false=未識別）
- `isCursed`: 呪い状態（true=呪い）
- `isBlessed`: 祝福状態（true=祝福）
