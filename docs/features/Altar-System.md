# Altar-System

## 1. 概要
祭壇システム（Altar System）は、ダンジョン内（フロンティアおよびマイ・ダンジョン）に存在する神秘的な構造物「祭壇（Altar）」を介して、プレイヤー、ダンジョン管理者、および侵入者（PKer）が神々の力と交渉し、戦略的なバフ、デバフ、または環境変化を引き起こすシステムです。
本システムは、探索中のリソース（ゴールド、余剰装備、食料）の新たな活用先を提示し、管理者にとっては自前モンスターの強化やリアルタイム介入の選択肢を増やし、PKerにとってはハイリスク・ハイリターンな戦術を可能にすることで、RogueF の多角的なプレイスタイルを深化させます。

## 2. 神々の種類と神罰・加護効果
祭壇はそれぞれ特定の「神」に捧げられており、神の種類によって得られる加護（バフ）や、不敬を働いた際の神罰（デバフ）の内容が異なります。

| 神の名称 | 司る属性・概念 | 特徴的な加護（DIVINE_BLESSING） | 不敬・神罰（DIVINE_PUNISHMENT） |
| :--- | :--- | :--- | :--- |
| **戦神アレス (Ares)** | 火属性 / 闘争 | 物理攻撃力 +15%、クリティカル率 +10% | 攻撃不可（スタン類似）、または敵対モンスターが周囲に即時召喚される。 |
| **護神アテナ (Athena)** | 光属性 / 守護 | 防御力 +20%、すべての状態異常と呪いの即時解除 | 防御力半減 (0.5倍)、受ける状態異常の持続時間が2倍。 |
| **豊穣神デメテル (Demeter)** | 木属性 / 豊穣 | 満腹度 +50 回復、HP/STの自然回復量が1.5倍に向上 | 満腹度の即時 0化（飢餓状態突入）、または食料が「腐った食料」化する。 |
| **運神フォルトゥナ (Fortuna)** | 無属性 / 幸運 | 運（Luck）+50、未識別アイテムの自動識別（3個まで） | 手持ちの装備品からランダムに1つが「呪い（CURSE）」状態になる。 |

## 3. 各役割におけるシステムとアクション

### 3.1 冒険者（Explorer）のアクション
冒険者はダンジョン探索中にランダムまたは管理者が配置した祭壇を発見し、以下の 2 つのアクションを行うことができます。

1. **祈る (Pray)**
   - **条件**: 各階層の祭壇で 1 回のみ実行可能（スタミナ消費なし、満腹度 2 消費）。
   - **効果**:
     - 満腹度が 50% 以上、かつ状態異常がない場合、低確率（Luckに比例）で、その祭壇に捧げられた神の「神の加護（DIVINE_BLESSING）」が 100 行動の間付与されます。
     - 装備に呪いがかかっている場合、護神アテナの祭壇に祈ることで、500G を支払うかわりに呪いを解く（解呪）ことができます。
2. **捧げる (Offer)**
   - **条件**: インベントリ内の任意のアイテムまたはゴールドを祭壇に捧げます（1アイテムまたは任意のゴールド量を消費）。
   - **効果**:
     - **適切な捧げ物（祝福品、高Tier武器・防具、新鮮な食料、大量のゴールド）**: 捧げ物の価値（Value）に応じて「神の恩寵（Divine Favor）」ポイントがダンジョンに蓄積され、プレイヤーには強力な加護（全ステータス 1.1倍、150行動継続）が与えられます。
     - **不適切な捧げ物（呪われた品、腐った食料、価値 10G未満のゴミアイテム）**: 神の逆鱗に触れ、即座に「神罰（DIVINE_PUNISHMENT）」が付与されます。

### 3.2 ダンジョン管理者（Administrator）のシステムとアクション
管理者はダンジョンの所有者として、祭壇を建設・カスタマイズし、侵入者を撃退するための強力な防衛拠点として運用できます。

1. **祭壇の設置と神の指定**
   - 祭壇は「施設（PlacedFacility）」の一種として、建築システムから設置できます。
   - **設置コスト**: 石材 × 15、魔力結晶 × 10、ゴールド × 3,000。
   - 設置時に、アレス、アテナ、デメテル、フォルトゥナのいずれかを指定して祭壇を稼働させます（変更には 1,000G の再設定コストが必要）。
2. **管理者への恩恵（常時フロアバフ）**
   - 祭壇が設置されているフロアでは、管理者の配下モンスター（Admin faction）に神々のテーマに応じた常時バフが適用されます。
     - 例：アレスの祭壇があるフロアの配下モンスターは常時 **物理攻撃力 1.1倍**。
3. **神託・神罰の発動（管理者介入システムとの連携）**
   - 冒険者がその祭壇に適切な捧げ物をして「神の恩寵」ポイントが蓄積されると、管理者はその恩寵ポイントを消費して、以下の「管理者リアルタイム介入」を実行できます。
     - **神の雷鳴 (Divine Thunder)**: 恩寵 50点消費。指定した座標（侵入者の位置など）とその周囲 3×3 マスに火属性 of 必中雷撃ダメージ（30ダメージ）を発生させる。
     - **慈愛の雨 (Graceful Rain)**: 恩寵 30点消費。フロア内のすべての配下（Admin）モンスターのHPを全回復し、状態異常を治癒する。

### 3.3 侵入者（PKer）のアクション
PKer はダンジョン侵入時、他プレイヤーの妨害や自身の生き残りのために、祭壇に対して極めて不遜なアクションを取ることができます。

1. **祭壇を穢す / 略奪する (Desecrate / Loot)**
   - **条件**: 稼働中の祭壇に隣接して実行可能（1回のみ、行動消費あり）。
   - **効果**:
     - 祭壇にこれまでに蓄積されていたゴールド（冒険者が捧げた分、最大 2,000G）および、捧げられていたアイテムを最大 1 つ強奪し、自身のインベントリ、または脱出時に Warehouse に転送します。
     - 実行時、PKer は **「激昂（RAGE）」と「加速（SPEED_UP）」** のバフ効果を 100 行動の間獲得し、戦闘力が爆発的に向上します。
   - **対価とリスク**:
     - 略奪を行った瞬間、PKer にはフロアを脱出するまで解除不可能な **「神罰（DIVINE_PUNISHMENT）」** 状態が付与されます。
     - 神罰状態の間、本来は攻撃対象の優先順位が低い野生モンスター（Wild faction）が超攻撃的に PKer を追尾するようになり、さらにフロア内のすべてのトラップの起動率が 100% になり、受けるトラップダメージが 2 倍になります。

## 4. 状態異常「神の加護」と「神罰」の定義
本システム導入に伴い、以下の 2 つの特殊な状態異常が追加されます。

1. **神の加護 (DIVINE_BLESSING - 強化バフ)**
   - **効果**: 攻撃力、防御力、素早さが 1.1倍に向上。
   - **持続時間**: 通常 100 行動（アクション）。アイテム「聖水」の使用によって持続時間が +50 アクション延長されます。
2. **神罰 (DIVINE_PUNISHMENT - 弱体化デバフ)**
   - **効果**:
     - 満腹度の減少速度が 2.0倍になる。
     - 野生モンスター（Wild）、防衛モンスター（Admin）の両方から最優先ターゲットとして認識される。
     - トラップ発見率・解除成功率が 0% になり、踏んだトラップのダメージが 2.0倍になる。
   - **解除方法**: 拠点に戻る（死亡またはクリア）、または「聖水」を祭壇に捧げることで即時解除可能。

## 5. データモデルの定義

### 5.1 PlacedFacility への 'altar' の追加
施設配置インタフェース `PlacedFacility` の `typeId` に `altar` を追加し、設定情報を保持する `AltarConfig` を `src/@types/admin.d.ts` に定義します。

```typescript
// src/@types/admin.d.ts 内の定義拡張

interface PlacedFacility {
  typeId: 'recovery_spring' | 'teleport_gate' | 'shop_counter' | 'synthesis_workshop' | 'torch' | 'statue' | 'altar';
  position: { x: number, y: number };
  config?: RecoverySpringConfig | TeleportGateConfig | StatueConfig | AltarConfig;
}

interface AltarConfig {
  deityType: 'ares' | 'athena' | 'demeter' | 'fortuna'; // 捧げられている神
  divineFavorPoints: number;                           // 蓄積された神の恩寵ポイント
  lootableGold: number;                                 // 略奪可能な蓄積ゴールド量
  isDesecrated: boolean;                                // PKerに穢された（略奪された）フラグ
}
```
