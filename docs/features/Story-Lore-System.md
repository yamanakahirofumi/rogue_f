# Story-Lore-System

## 1. 概要
ストーリー・世界観システムは、RogueF の世界を構成する背景（Lore）、NPC との会話、および探索をさらに奥深く、魅力的にするための仕組みです。プレイヤーはダンジョンの最深部を目指す明確な目的を持ち、ダンジョン管理者は世界の成り立ちに基づいた設定を自身の「マイ・ダンジョン」に反映させることができます。

---

## 2. コアコンセプトと世界観設定

### 2.1 フロンティアの起源
絶えず変化するランダムダンジョン **「フロンティア」** は、遥か古代に栄えた超文明の遺産であり、地下深くに眠る **「原初の結晶（Primordial Crystal）」** の鼓動によって自己再構成を繰り返しているとされています。
- この結晶のエネルギーを抽出・制御する能力を持った存在が **「管理者」** であり、抽出した力を用いて創り出す独自の防衛領域が **「マイ・ダンジョン」** です。
- 野生のモンスターは、結晶が発する魔力の歪み（マナ・ストーム）によって実体化した存在であり、これを手懐けることで管理者は使役・繁殖を行うことが可能になります。

### 2.2 探索の目的
プレイヤー（Explorer）は、冒険者ギルドの依頼を受け、拡大を続けるフロンティアの謎を解き明かすために深層へ挑みます。深層の「碑文」や「遺物」を調べることで、世界が崩壊の危機に瀕している原因と、管理者たちが独自に世界（サーバー）を構築するに至った歴史が徐々に解き明かされます。

---

## 3. アンロックのメカニズム
ストーリーおよび世界観の断片（Lore Fragment）は、プレイヤーが特定の条件を達成することでアンロックされます。

### 3.1 アンロック条件のバリエーション
1.  **特定階層への到達**: フロンティアの 5F、10F、20F などの特定階層へ到達した際、自動的に関連ストーリーがアンロック。
2.  **ダンジョン内での「碑文」「遺言」の調査**: ダンジョン内にランダム、または固定で配置される「古代の碑文（Monolith）」や「先駆者の遺言（Remains）」を調べることでアンロック。
3.  **特定のモンスターの撃破・飼育**: 特定のレアモンスター（例：キングスライム等）を初めて撃破した時、または管理者が初めて成体に育てた時にアンロック。
4.  **合成・アイテムの特定行動**: 特定のアーティファクトを合成・入手した際や、未識別の特殊装備を鑑定した際にアンロック。

### 3.2 記録と保存
- プレイヤーがアンロックしたストーリーや Lore の情報は、プレイヤーデータモデルの `unlockedLoreIds: string[]` 配列に追加されます。
- アンロック情報はセーブデータに永続化され、拠点にあるギルドの「書庫」からいつでも再確認することができます。

## 4. NPC会話システム
拠点（[拠点システム](Base-System.md)）に存在する主要NPCとの会話は、プレイヤーの進行状況（アンロックされた `unlockedLoreIds` や最高到達階層）に応じて動的に変化します。

### 4.1 主要NPCと役割
-   **ギルドマスター・アルヴァ (Guild Master Alva)**:
    - プレイヤーに対してフロンティア探索の意義を説明し、最高到達階層に応じたメインストーリーを進行させる。
    - 「原初の結晶」の暴走を食い止めるための調査を依頼する。
-   **歴史学者ルミナ (Historian Lumina)**:
    - プレイヤーがダンジョンから持ち帰った「碑文の写し」や「古代の遺物」を解読し、世界の創世神話や管理者たちの誕生秘話について解説する。
-   **放浪の商人（Wandering Merchant）**:
    - ダンジョン内または拠点に低確率で出現。世界の秘密を知る、怪しげなセリフと共に高レアリティのレシピや未識別アイテムを販売する。

### 4.2 会話の変化ルール
会話イベントが発生する際、以下の優先度に従ってメッセージが抽選されます。
1.  **未読のメインストーリーイベント会話**: 条件を満たしており、かつ一度も再生されていない最優先の会話。
2.  **特定の Lore アンロックに伴う特殊セリフ**: `unlockedLoreIds` に対応する解釈会話。
3.  **進行度（到達階層）に応じた通常会話**: プレイヤーの強さや進行に合わせたアドバイスなど。
4.  **汎用日常セリフ**: ランダムに抽選される基本的なセリフ。

## 5. UI・UX設計

### 5.1 ギルドの「書庫」画面 (Lore Journal)
プレイヤーは、拠点エリアから「書庫」メニューにアクセスすることで、これまでに収集したストーリー情報を閲覧できます。
-   **ストーリーアーカイブ**: メインクエストや歴史の全体像を時系列で整理したテキストビュー。
-   **遺物・碑文図鑑**: アンロックされた碑文の原文と、ルミナによる解読結果。
-   **未解決の謎（ヒント）**: まだ見ぬ Lore を解放するための条件やヒントを、ぼかした表現で表示（例：「氷雪の地で、深き眠りに就く王の息吹を感じよ」など）。

### 5.2 アンロック時の演出
ダンジョン探索中、または戦闘後に Lore が解放された場合、画面上部に「**Lore解放: [遺物の名称]**」というトースト通知がダイナミックに表示され、プレイヤーの収集欲を刺激します。

## 6. 技術的仕様とデータスキーマ

### 6.1 データ構造の拡張
プレイヤーモデル（`Player`）に、ストーリー・Lore のアンロック状態を保持するプロパティを格納します。

```typescript
// Player データのスキーマ拡張
interface Player {
  // ... 既存のフィールド
  unlockedLoreIds?: string[]; // 解放済みのストーリー/世界観IDリスト
}
```

### 6.2 Lore 定義モデル (LoreDefinition)
各ストーリー・Lore データは、以下のメタデータ構造に従って定義されます。

```typescript
interface LoreDefinition {
  id: string;              // Lore 固有 ID (例: 'lore_frontier_origin')
  title: string;           // タイトル (例: '原初の結晶の記憶')
  category: 'main' | 'history' | 'monster' | 'artifact'; // カテゴリ
  unlockConditionText: string; // アンロックのヒントテキスト
  unlockedAt?: number;     // アンロックされたUNIXタイムスタンプ (プレイヤー保存用)
  contentRows: string[];   // 解放されるテキスト内容
}
```
