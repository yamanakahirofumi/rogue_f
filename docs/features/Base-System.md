# Base-System

## 1. 概要
拠点（Base / Town）は、プレイヤーが冒険の準備を整え、管理者が自身のダンジョンやリソースを運営するための中心的なハブエリアです。戦闘やトラップの危険がない安全地帯であり、プレイヤーと管理者の双方が次の活動に向けて必要な操作を行います。

## 2. 拠点の役割

### 2.1 プレイヤーにとっての拠点
- **冒険の準備**: インベントリの整理、装備の変更、食料の確保。
- **全回復 (Full Recovery)**: 拠点（ベース）に滞在している間、プレイヤーの HP、スタミナは即座に最大値まで回復し、全ての状態異常（毒、呪い等を除く一時的なデバフ）が解除されます。
- **リソース消費の停止**: 拠点エリア内では、時間経過や移動に伴う**満腹度およびスタミナの減少は発生しません。**
- **ダンジョンへの出発**: ランダムダンジョン（フロンティア）や他のプレイヤーの「マイ・ダンジョン」へ挑戦するためのゲートウェイとして機能します。
- **帰還時の報酬確認**: ダンジョンから無事に脱出、またはクリアした際の戦利品を整理します。

### 2.2 管理者にとっての拠点
- **リソース管理**: 収集したモンスター、アイテム、資材の管理。
- **ダンジョン構築**: 「マイ・ダンジョン」のデザインと編集。
- **経済・連携管理**: ショップの運営設定や、他のサーバーとの信頼関係（トラストネットワーク）の構築。

## 3. 拠点内の主要施設

拠点は複数の専門的なエリアや施設で構成されています。

### 3.1 繁殖施設 (Breeding Facility)
- 捕獲したモンスター同士を掛け合わせ、新たな個体（卵）を生み出します。
- 詳細は **[モンスター繁殖システム](Monster-Breeding-System.md)** を参照してください。

### 3.2 合成工房 (Synthesis Workshop)
- 探索で入手した資材を消費して、アイテムや上位の資材、装備品を生成します。
- 詳細は **[合成システム](Synthesis-System.md)** を参照してください。

### 3.3 倉庫 (Warehouse)
- モンスター、アイテム、建築資材を安全に保管します。
- 管理者はここからダンジョンへの配置物やショップの商品を選定します。
- 詳細は **[倉庫システム](Warehouse-System.md)** を参照してください。

### 3.4 ダンジョンゲート (Dungeon Gate)
- 外部の世界（ダンジョン）へ接続するための施設です。
- **フロンティア（ランダムダンジョン）**: 資源確保のための探索エリア。
- **マイ・ダンジョン**: 自身が構築した、または他者が公開しているデザインダンジョン。

## 4. 移動と遷移 (Transition)

### 4.1 拠点からダンジョンへ
- プレイヤーは拠点内のゲートやメニューから、挑戦したいダンジョンを選択して入場します。
- 入場時には、必要に応じて「入場料」が消費されます。

### 4.2 ダンジョンから拠点へ
ダンジョンから拠点へ戻るには、以下のいずれかの条件を満たす必要があります。詳細は **[機能仕様書](Functional-Specification.md#2-3-ダンジョンクリアと脱出の条件)** を参照してください。

- **脱出 (Escape)**: 1階（1F）にある「上り階段」を使用する。
- **クリア (Clear)**: 最終階層にある「下り階段」を使用する。
- **ゲームオーバー (Death)**: HP が 0 になり、死亡する（ペナルティが発生します）。
