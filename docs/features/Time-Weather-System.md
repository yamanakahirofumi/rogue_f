# 昼夜・天候システム (Time & Weather System)

## 1. 概要
昼夜・天候システム（Time & Weather System）は、RogueF の世界に動的な時間経過と環境変化を導入し、探索、戦闘、およびリソース管理における戦略の多様性とサバイバル要素を深化させるためのゲームシステム提案です。

リアルタイムローグライクである本作において、時間帯（昼夜）や天候の移り変わりは、プレイヤーの視界、ステータス、アクションコスト、モンスターの出現分布や強さ、さらには釣りなどの環境インタラクションに対して直接的かつ動的な影響を及ぼします。

---

## 2. 時間経過と昼夜サイクル

ゲーム内の時間は、サーバー側およびクライアント側で共通の「メインティック（Ticks）」に基づいて管理されます。

### 2.1 サイクル構成
ゲーム内の一日は、以下の通り「昼（Day）」と「夜（Night）」の 2 つの時間帯に等しく分割されます。

- **1 サイクル（一日）の長さ**: **120 ティック**（現実時間で約 20 分相当）。
- **昼の時間帯 (Day)**: 0 〜 59 ティック。太陽光が差し込み、安定した探索が可能です。
- **夜の時間帯 (Night)**: 60 〜 119 ティック。闇が支配し、視界が大幅に減少する一方で、特定のモンスターが活性化します。
- **時間帯の遷移表示**: 昼から夜、夜から昼への切り替わり時（例: 55〜60ティック、115〜0ティック）には、画面の外観色（カラーオーバーレイ）が徐々に変化し、効果音（SE）やメッセージ（「夕闇が迫ってきた……」「夜が明けた！」）によって、段階的に時間帯の移り変わりが表現されます。

## 3. 天候システム

ダンジョン内の各フロア（または拠点）では、その階層が属する**バイオーム（Biome）**および現在の時間帯に応じて、動的に天候が決定・更新されます。

### 3.1 天候の種類と基本効果
天候は一定のティック数（例: 20 〜 40 ティック）ごとに確率判定され、変化します。

| 天候 ID | 名称 | 主な影響 | 備考 |
| :--- | :--- | :--- | :--- |
| `CLEAR` | 晴れ | 標準的な環境。補正なし。 | すべてのバイオームで基本となる天候。 |
| `RAIN` | 雨 | 炎属性ダメージ -15%、水属性ダメージ +15%。釣りヒット率向上。 | 森林バイオームで発生しやすい。 |
| `FOG` | 霧 | 視界半径 -2。全キャラクターの命中率 -20%。 | 洞窟や森林で発生しやすい。 |
| `BLIZZARD` | 吹雪 | 氷雪以外の全属性の移動速度・攻撃速度低下。スタミナ回復半減。 | 氷雪バイオーム特有の過酷な天候。 |
| `HEATWAVE` | 熱波 | 満腹度消費 1.5 倍、スタミナ消費 1.2 倍。炎ダメージ +15%。 | 溶岩バイオーム特有の過酷な天候。 |

### 3.2 バイオーム別天候発生確率テーブル
天候変化の判定時に使用される、バイオームごとの確率分布（重み付け）です。

| バイオーム | 晴れ (`CLEAR`) | 雨 (`RAIN`) | 霧 (`FOG`) | 吹雪 (`BLIZZARD`) | 熱波 (`HEATWAVE`) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **拠点 (Base Area)** | 80% | 15% | 5% | 0% | 0% |
| **洞窟 (Cave)** | 60% | 0% | 40% | 0% | 0% |
| **森林 (Forest)** | 50% | 35% | 15% | 0% | 0% |
| **氷雪 (Ice)** | 30% | 0% | 20% | 50% | 0% |
| **溶岩 (Lava)** | 40% | 0% | 0% | 0% | 60% |

## 4. 他システムとの相互作用

### 4.1 視界システム（Visibility System）への影響
時間帯と天候は、プレイヤーの視界半径に直接影響を与えます。
- **夜間 (`NIGHT`)**: プレイヤーの基本視界半径が **5 マスから 3 マスに縮小** されます。松明（`torch`）を装備または設置することで、縮小を緩和できます。
- **霧 (`FOG`)**: 昼夜を問わず、視界半径が **2 マス縮小**（最低 1 マス保証）されます。
- 詳細は **[視界システム](Visibility-System.md)** を参照してください。

### 4.2 戦闘・属性システム（Combat & Attribute System）への影響
天候や時間帯に応じて、特定の属性攻撃や戦闘ステータスが補正されます。
- **属性ダメージ補正**:
  - `RAIN`（雨）: **炎属性ダメージ × 0.85**、**水属性ダメージ × 1.15**
  - `HEATWAVE`（熱波）: **炎属性ダメージ × 1.15**、**水属性ダメージ × 0.85**
  - `BLIZZARD`（吹雪）: **水・氷属性ダメージ × 1.15**、**木属性ダメージ × 0.85**
- **夜間の闇討ちボーナス**:
  - プレイヤーまたはモンスターが闇（照明範囲外かつ夜間）から攻撃を仕掛けた際、クリティカル発生率が **+10%** 上昇します。

### 4.3 アクション・自然回復システム（Action & Natural Recovery System）への影響
過酷な天候下では、生存リソースの消費速度が加速します。
- **吹雪 (`BLIZZARD`)**:
  - プレイヤーの体温低下を表現するため、自然回復（HP/ST）の間隔が 2.0 倍（10秒周期から 20秒周期に遅延）となります。ただし、氷属性耐性を持つ装備を装着している場合は、このデバフを無効化できます。
- **熱波 (`HEATWAVE`)**:
  - 発汗による脱水を表現するため、**満腹度（Satiety）の消費が常時 1.5 倍** に増加し、**アクション時のスタミナ（ST）消費が 1.2 倍** になります。

### 4.4 釣りシステム（Fishing System）への影響
時間帯と天候は、釣りにおける獲物のヒット率やレア魚の出現率を大きく変える要因となります。
- **夜間釣り**:
  - 夜間のみ出現する特別なレア魚（例: `fish_glowing_slime`）が追加され、ヒット率が全体的に **+10%** 向上します。
  - 発光エサ（`bait_glowing`）を夜間に使用した場合、相乗効果によりヒットまでの待機時間がさらに 15% 短縮されます。
- **雨 (`RAIN`)**:
  - 水面が揺れて魚の警戒心が薄れるため、釣りヒットまでの待機時間が **20% 短縮** されます。
- 詳細は **[釣りシステム](Fishing-System.md)** を参照してください。

### 4.5 状態異常システム（Status Effect System）への影響
極限状態の天候に長時間（10 ティック以上）身を晒し続けた場合、以下の新たな環境デバフが自動的に付与されるリスクが発生します。

- **凍結・冷気状態 (`CHILLED`)**:
  - `BLIZZARD` の中で熱源（松明など）から 5 マス以上離れている場合、毎メインティック 5% の確率で付与されます。
  - **効果**: 移動速度・攻撃速度（クールタイム）が **1.3 倍** になり、スタミナ（ST）の自然回復が停止します。
- **熱中症・熱気状態 (`OVERHEATED`)**:
  - `HEATWAVE` の中で冷却手段（氷結タラのホイル焼き効果など）がない場合、毎メインティック 5% の確率で付与されます。
  - **効果**: 5 秒ごとに 2 ポイントの固定ダメージ（脱水症状）を受け、命中率が 15% 低下します。
- 詳細は **[状態異常システム](Status-Effect-System.md)** を参照してください。

### 4.6 モンスターシステム（Monster System）への影響
特定の時間帯や天候下で、モンスターが狂暴化、あるいは出現しやすくなります。
- **夜行性モンスターの活性化**:
  - `bat`（コウモリ）や `skeleton`（スケルトン）などの夜行性モンスターは、夜間 (`NIGHT`) において**全能力値（HP、ATK、DEF、SPD）が 1.15 倍** に強化されます。
- **出現率（スポーン）の変動**:
  - 夜間は、出現する野生モンスターに `ghost`（ゴースト）や `mimic`（ミミック）などのより厄介な種別が追加され、全体の出現密度が最大 1.2 倍に上昇します。詳細は **[ドロップ品・出現システム](Loot-and-Spawn-System.md)** を参照。

## 5. 技術データ構造と型定義

本システムの時間を永続化し、通信を行うため、**[Playerデータモデル](../@types/player.d.ts)** および関連モデルを拡張します。

### 5.1 ワールド時間・天候状態の型定義 (`WorldTimeState`)
```typescript
interface WorldTimeState {
  timeOfDay: 'day' | 'night';                                  // 現在の時間帯
  totalTicks: number;                                          // ゲーム全体の累積経過ティック
  currentTickInCycle: number;                                  // 現在の一日のサイクル内ティック (0〜119)
  currentWeather: 'clear' | 'rain' | 'fog' | 'blizzard' | 'heatwave'; // 現在の天候
  weatherTicksRemaining: number;                               // 現在の天候が継続する残りティック数
}
```

### 5.2 Player データモデルの拡張
```typescript
// Player クラス/インターフェースに、現在のワールドの時間を参照するための読み取り専用、
// またはサーバーから同期されるプロパティを追加
declare class Player {
  // ...既存のプロパティ
  worldTimeState?: WorldTimeState;                             // 現在の階層/ワールドの昼夜・天候状態
}
```
