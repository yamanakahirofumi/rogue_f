# モンスター図鑑システム (Monster Bestiary System)

## 1. 概要
モンスター図鑑システム（Monster Bestiary System）は、プレイヤーがゲーム内で遭遇、撃破、捕獲、または繁殖させたモンスターの記録を自動的に記録・収集し、段階的にその詳細情報を解放していくシステムです。
このシステムは、プレイヤーの「収集欲」を満たすだけでなく、図鑑を埋めることによる実用的な戦闘バフ（調査ボーナス）や、ダンジョン管理における効率向上（繁殖や配置へのアドバンテージ）を提供し、ゲーム全体の長期的なモチベーションと探索の深みを強化します。

## 2. 図鑑の記録条件と解放段階

### 2.1 記録のトリガー
プレイヤーが「探索者（Explorer）」「管理者（Administrator）」「PKer（乱入者）」として活動する中で、以下のイベントが発生した際に図鑑が更新されます。
- **遭遇 (Encounter)**: プレイヤーの視界内に対象モンスターが存在した状態。詳細は [視界システム](Visibility-System.md) を参照。
- **撃破 (Defeat)**: プレイヤー自身または設置したトラップ、所有モンスターによって対象モンスターを倒した状態。詳細は [戦闘システム](Combat-System.md) を参照。
- **捕獲 (Capture)**: 捕獲の球などのアイテムを使用し、対象モンスターの捕獲に成功した状態。詳細は [モンスターシステム](Monster-System.md) を参照。
- **繁殖 (Breed)**: [モンスター繁殖システム](Monster-Breeding-System.md)によって対象モンスターの卵を孵化させた状態。

### 2.2 解放段階と情報レベル (Research Levels)
各モンスターの図鑑データは、以下の 4 つの「調査レベル（Research Level）」によって管理され、達成状況に応じて開示される情報が段階的に拡張されます。

| 調査レベル | 解放条件 | 開示される情報 | 調査ボーナス |
| :---: | :--- | :--- | :--- |
| **Lv 0 (未遭遇)** | なし | 記号 `?` とシャドウ、種族ID非公開。 | なし |
| **Lv 1 (遭遇済)** | 対象と遭遇する、または捕獲/孵化させる。 | モンスターの基本名、属性、出現バイオーム、Tier。 | 対象モンスターへの物理ダメージが常に **+1%** される。 |
| **Lv 2 (調査進行)** | 累計撃破数 **10体**、または捕獲/繁殖で累計 **1体** 獲得する。 | 基礎ステータス（最大HP、最大ST、攻撃力、防御力、敏捷性、器用さ、素早さ、運、射程、行動インターバル）。 | 対象モンスターへの物理ダメージが常に **+3%** に強化され、捕獲確率が **+2%** 向上する。 |
| **Lv 3 (完全解析)** | 累計撃破数 **50体**、または捕獲/繁殖で累計 **5体** 獲得する。 | 所持しているすべての特殊行動（スキル）の発動条件・消費ST、固有ドロップアイテムとその確率、および初期特性の一覧。 | 対象モンスターへの物理ダメージが常に **+5%** に強化、捕獲確率が **+5%** 向上し、その種族を繁殖させる際の孵化時間がさらに **10% 短縮** される。 |

## 3. 図鑑メニューの UI・UX 仕様

### 3.1 図鑑画面の構成
拠点（Base）の「コレクションメニュー」またはポーズ中の「図鑑」画面からアクセス可能です。

- **フィルターと検索機能**:
  - **バイオーム別**: 洞窟、森林、氷雪、溶岩、特殊に分類。詳細は [バイオーム・環境システム](Biome-System.md) を参照。
  - **属性別**: 火、水、木、光、闇、無に分類。詳細は [属性システム](Attribute-System.md) を参照。
  - **Tier別**: Tier 1、Tier 2、Tier 3、Special/Bossに分類。詳細は [モンスターマスターリスト](Monster-Master-List.md) を参照。
- **モンスター詳細パネル**:
  - **ビジュアル**: 3Dまたは2Dドット絵のプレビュー（未遭遇はシルエット表示、完全解析時はアニメーション動作の再生が可能）。
  - **撃破/捕獲/繁殖カウンター**: プレイヤーがその種族を何体倒したか、何体手に入れたかが表示される。
  - **解説テキスト（フレーバーテキスト）**: 世界観におけるモンスターの生態、起源、または管理者が繁殖時に注目すべき遺伝的特性のヒント。

## 4. 他システムとの動的連携

### 4.1 称号・実績システムとの連携
モンスター図鑑の収集度（コンプリート率）に応じて、特別な称号がアンロックされます。詳細は [称号・実績システム](Title-System.md) を参照してください。

- **新米コレクター** (`novice_collector`):
  - **解除条件**: 図鑑登録数を **5 種**（Lv 1 以上）にする。
  - **効果**: 捕獲の球 (`capture_ball`) の購入価格が 10% 割引。
- **魔物大図鑑の著者** (`bestiary_author`):
  - **解除条件**: 全モンスターの 80% 以上の図鑑調査レベルを **Lv 3 (完全解析)** にする。
  - **効果**: プレイヤーの「運 (Luck)」ステータスが **+5** される。

### 4.2 クエストシステムとの連携
特定のモンスターの調査レベルを上げる、または図鑑を埋めること自体がクエストの達成条件として設定されます。詳細は [クエストシステム](Quest-System.md) を参照してください。

## 5. 技術データ構造 (Technical Data Structures)

### 5.1 Playerデータモデルの拡張
プレイヤーの図鑑記録を永続的に保存するため、**[Playerデータモデル](../@types/player.d.ts)** に以下のプロパティを追加します。

```typescript
// Playerクラス/インターフェースに追加されるプロパティ
bestiaryProgress?: BestiaryEntry[]; // モンスター図鑑の収集状況
```

### 5.2 BestiaryEntry（図を図鑑個別レコード）インターフェース
```typescript
interface BestiaryEntry {
  monsterTypeId: string;       // 対象モンスターの種別ID (例: 'slime', 'dragon')
  encounterCount: number;      // 遭遇回数
  defeatCount: number;         // 撃破回数
  capturedCount: number;       // 捕獲回数
  bredCount: number;           // 繁殖（孵化）回数
  researchLevel: 0 | 1 | 2 | 3; // 現在の調査レベル (0: 未遭遇, 1: 遭遇済, 2: 調査進行, 3: 完全解析)
}
```
