# Monster-Trait-List

## 1. 概要
モンスター特性（Traits）は、モンスター個体が持つ特別な能力や性質です。特性はステータスの補正や、戦闘、探索における特殊な効果をもたらします。特性は野生個体が稀に持っているほか、[モンスター繁殖システム](Monster-Breeding-System.md) を通じて子に継承されることがあります。

## 2. 特性パラメータ
各特性は以下の属性を持ちます。

- **ID**: システム上の識別子。
- **名称**: 特性の表示名。
- **効果**: 特性がもたらす具体的なメリット（またはデメリット）。
- **レアリティ**: 特性の希少度（Common, Rare, Epic）。継承率や突然変異率に影響します。

## 3. ステータス補正系特性
基礎ステータスを強化または変化させる特性です。

| `sharp_claws` | 鋭い爪 | 攻撃力 +10%, クリティカル率 +5% | Common |
| `quick_reflexes` | 素早い反応 | 素早さ +15%, 回避率 +5% | Common |
| `sturdy_body` | 頑丈な体 | 最大HP +20% | Common |
| `keen_eye` | 鋭い眼光 | 器用さ +15%, 命中率 +10% | Common |
| `lucky_clover` | 幸運の持ち主 | 運 (Luck) +5 | Rare |

特定の状況下で発動する、またはステータス以外の要素に影響する特性です。

| ID | 名称 | 効果 | レアリティ |
| :--- | :--- | :--- | :--- |
| `poison_touch` | 毒の体 | 物理攻撃時に 15% の確率で対象を「毒」状態にする。 | Rare |
| `regenerative` | 自己再生 | 5秒ごとに最大HPの 1% を回復する。 | Epic |
| `mana_absorb` | 魔力吸収 | 攻撃時に与えたダメージの 5% 分、自身のスタミナ（または魔力）を回復する。 | Rare |
| `cowardly_dash` | 逃げ足 | HPが 25% 以下の時、移動速度が 1.5 倍になる。 | Common |
| `alpha_soul` | アルファの魂 | 同階層にいる味方モンスターの攻撃力を +5% する。詳細は後述。 | Epic |
| `iron_will` | 鉄の意志 | スタン状態になる確率を 50% 軽減する。 | Rare |
| `flying` | 飛行 | 全ての地形トラップ・環境効果（ダメージ、減速）を無視する。 | Rare |
| `aquatic` | 水棲 | 水地形での移動減速を無視し、回避率が **+20%** 向上する。 | Common |
| `fire_affinity` | 火属性 | 溶岩によるダメージを無効化する。詳細は [属性システム](Attribute-System.md) 参照。 | Common |
| `water_affinity` | 水属性 | 水地形による行動インターバル遅延を無効化する。詳細は [属性システム](Attribute-System.md) 参照。 | Common |
| `wood_affinity` | 木属性 | 砂地による行動インターバル遅延を無効化する。詳細は [属性システム](Attribute-System.md) 参照。 | Common |
| `mimicry` | 擬態 | フィールド上でアイテム（`I`）として表示され、行動するまで正体を隠す。 | Rare |

### 4.1 特殊特性の補足仕様
#### アルファの魂 (`alpha_soul`)
- **味方の定義**:
    - [派閥システム](Faction-System.md#5-特性・効果における「味方」の定義) に基づき、同じ派閥に属するエンティティを「味方」と見なします。
- **効果の累積**:
    - この特性を持つモンスターが複数存在する場合、効果は**加算（Additive）**されます。
    - **累積上限**: 攻撃力の底上げによる極端なバランス崩壊を防ぐため、累積ボーナスの最大値は **+20%**（4体分）までとします。5体目以降が存在しても、ボーナスは +20% で固定されます。

### 4.2 固有特性 (Unique Traits)
特定の組み合わせの親からのみ、低確率（5%）で継承・発現する非常に強力な特性です。

| ID | 名称 | 効果 | レアリティ | 組み合わせ例 |
| :--- | :--- | :--- | :--- | :--- |
| `dragon_scale` | ドラゴンスケイル | 防御力 +20%, 全ての属性ダメージを 10% 軽減。 | Epic | ドラゴン × ゴーレム |
| `shadow_step` | 影走り | 移動時のスタミナ消費が 0 になる。 | Epic | シャドウ × コウモリ |
| `miracle_touch` | 奇跡の指先 | トラップの解除成功率が +20% 向上する。 | Epic | エンジェル × スライム |
| `toxic_body` | 毒の粘液 | 隣接する敵から攻撃を受けた際、30% の確率で対象を「毒」状態にする。 | Epic | ヴァンパイア × スライム |
| `holy_barrier` | 聖なる守り | 闇属性の攻撃から受けるダメージを 25% 軽減する。 | Epic | エンジェル × ゴーレム |
| `storm_wing` | 嵐の翼 | 敏捷性が +20% 向上し、回避率が +10% 加算される。 | Epic | ドラゴン × コウモリ |

## 5. 繁殖と継承
- 特性は繁殖時に親から子へ継承される可能性があります。詳細は [モンスター繁殖システム](Monster-Breeding-System.md) を参照してください。
- 突然変異により、両親が持っていない特性が発現することもあります。
