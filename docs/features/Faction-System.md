# Faction-System

## 1. 概要
派閥システムは、ダンジョン内のエンティティ（プレイヤー、モンスター、PKer）がどのグループに属し、誰を敵と見なし、誰を味方と見なすかを定義する仕組みです。このシステムは、戦闘におけるターゲット選択（AI）やトラップの発動条件、特定の特性の効果範囲を決定する基盤となります。

## 2. 派閥の分類
RogueF では、全てのエンティティを以下の 4 つの派閥（Faction）に分類します。

| 派閥名 | 英語名 | 説明 |
| :--- | :--- | :--- |
| **探索者** | Explorer | プレイヤーキャラクター。ダンジョンを攻略する主体。 |
| **野生** | Wild | ランダムダンジョン（フロンティア）に自然発生するモンスター。 |
| **管理者** | Admin | 管理者が「マイ・ダンジョン」に配置した、または介入によって召喚したモンスターや施設。 |
| **乱入者** | PKer | 他者の世界へモンスター形態で乱入しているプレイヤー。 |

## 3. 敵対・友好関係マトリクス
各派閥間の基本的な関係性（ターゲットにするかどうか）の定義です。

| 自身 \ 対象 | 探索者 | 野生 | 管理者 | 乱入者 |
| :--- | :---: | :---: | :---: | :---: |
| **探索者** (Player) | - | 敵対 | 敵対 | 敵対 |
| **野生** (Wild) | 敵対 | 友好 | 敵対 | 敵対 |
| **管理者** (Admin) | 敵対 | 敵対 | 友好 | 敵対 |
| **乱入者** (PKer) | 敵対 | 敵対 | 敵対 | - |

- **友好 (Ally)**: 攻撃対象にせず、回復やバフの効果対象となります。
- **敵対 (Hostile)**: 視界に入った場合、攻撃対象（ターゲット）と見なします。
- **管理者同士の友好**: 同じ管理者に所属するモンスターや施設間でのみ「友好」が成立します。異なる管理者のモンスター同士（例：世界間移動時）は「敵対」となります。
- **乱入者 (PKer) の扱い**:
    - PKer は探索者を撃破することが目的ですが、野生モンスターや管理者のモンスターからも攻撃を受けます。
    - **トラップとの相互作用**:
        - **野生のトラップ**: 全てのエンティティと同様、PKer が踏むと発動します。
        - **管理者設置のトラップ**: PKer を「侵入者」として検知し、発動します。

## 4. AI ターゲット優先度 (Targeting Priority)
モンスター（野生、管理者、PKerの自動行動時）が視界内に複数の敵対派閥を捉えた場合、以下の優先順位でターゲットを決定します。

1.  **探索者 (Explorer)**: 常に最優先。
2.  **乱入者 (PKer)**: 探索者がいない場合、または PKer から攻撃を受けた場合に優先。
3.  **その他の敵対エンティティ**: 最も距離が近い個体。

## 5. 特性・効果における「味方」の定義
[モンスター特性リスト](Monster-Trait-List.md) の **アルファの魂 (`alpha_soul`)** など、「味方」に影響を与える効果の判定ルールです。

- **判定基準**: 原則として、**「同じ派閥」かつ「同じ所有者（管理者の場合）」** であることを条件とします。
- **派閥ごとの味方範囲**:
    - **探索者**: パーティシステム（将来拡張）がない限り、自分自身のみ。
    - **野生**: 同じ階層にいる全ての野生モンスター。
    - **管理者**: 同じ管理者に所属し、配置・召喚されている全てのモンスター。
    - **乱入者**: 同じ乱入オーブの効果で一緒に乱入しているプレイヤー（将来拡張）がいる場合のみ、それらを味方と見なします。
