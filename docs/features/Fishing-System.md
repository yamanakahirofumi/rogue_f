# Fishing-System

## 1. 概要
釣りシステム（Fishing System）は、ダンジョン内の様々な水辺や溶岩、あるいは管理者が設置した専用施設「釣り堀（`fishing_point`）」を利用して、リソース（食料、資材、装備、アイテム）を獲得できるアクティブ生存・生産要素です。
満腹度、スタミナなどのリソース管理に加え、釣り上げた「凶暴な水生モンスター」との偶発的な戦闘リスクを伴うことで、RogueF のサバイバルダンジョン体験をより奥深いものとします。

## 2. 釣りの基本メカニズム

### 2.1 釣り道具の準備
釣りを行うためには、インベントリに「釣り竿（Fishing Rod）」と「エサ（Bait）」を準備し、釣り竿を装備または使用可能状態にする必要があります。
- **釣り竿のグレード**:
  - **木製釣り竿 (`rod_wood`)**: 初期段階の竿。低グレードのエサのみ使用可能。
  - **鉄製釣り竿 (`rod_iron`)**: 中級。耐久性が高く、中級グレードのエサに対応。
  - **魔力釣り竿 (`rod_magic`)**: 高級。全ての特別なエサに対応し、キャスト時の魚影察知時間が 20% 短縮される。
- **エサの種類**:
  - **ミミズ (`bait_worm`)**: 一般的なエサ。水辺での一般的な釣獲物に対応。
  - **光る虫 (`bait_glowing`)**: 発光するエサ。夜間や暗い洞窟バイオームでのヒット率を +15% 上昇。
  - **溶岩虫 (`bait_lava_worm`)**: 溶岩バイオーム専用のエサ。
  - **合成擬似餌 (`bait_lure`)**: 何度も使用可能なルアー。ロスト確率 10%。

### 2.2 釣りポイントの選定
プレイヤーは、以下のタイルのいずれかに隣接（上下左右の 1 マス以内）している場合に釣りを開始できます。
- **水辺 (`water`)**: 洞窟、森林、氷雪バイオームに自然発生する水、または管理者が配置した水源。
- **溶岩 (`lava`)**: 溶岩バイオームに存在するマグマ。
- **氷穴 (`ice_hole`)**: 氷雪バイオームで、氷の床（`ice`）を破壊または削ることで出現する釣り穴。
- **釣り堀 (`fishing_point`)**: 管理者が設置可能な施設（詳細は後述）。

### 2.3 キャスティングと待機
1. **キャストコマンド**: 釣り竿とエサを装備・選択した状態で、釣りポイントに向かって「キャスト（投げる）」アクションを行います。
2. **リソース消費**: キャスト時、**満腹度（Satiety）を 0.5**、**スタミナ（ST）を 2** 消費します。
3. **待機時間（Ticks）**: キャストからヒット（魚の引き）までのメインティック数は、プレイヤーの**器用さ（Dexterity）**および**運（Luck）**、そしてエサの品質によって動的に決定されます。
   - `待機時間 (秒) = BaseWaitTime (10〜30秒) * (1 - (Dexterity * 0.002 + Luck * 0.005)) * BaitMultiplier`
   - 待機時間が 0 秒を下回ることはなく、最小待機時間は 3 秒に制限されます。

### 2.4 フッキングとタイミング判定
ヒットが発生すると、プレイヤーの画面上に「❗」のエフェクトまたは効果音（SE）が再生され、タイミング・クイックタイムアクション（Hooking）が発生します。
- **タイミングウインドウ**: ヒットから **1.5秒〜2.5秒**（プレイヤーの素早さ Agility と運 Luck で増加）の間に再度「アクションキー（決定/引っ張る）」を入力する必要があります。
- **判定結果**:
  - **大成功 (Perfect)**: 最高のタイミングで入力。魚影テーブル内の「高品質/レア」の獲得率が 20% 上昇。
  - **成功 (Success)**: 標準的なタイミングで入力。通常通り獲得。
  - **失敗 (Failed)**: 入力が遅れた、または早すぎた。エサが消費され、獲物を失います。

## 3. 釣獲物（獲物）とバイオーム依存ルール

### 3.1 バイオーム別の釣獲物テーブル
釣りポイントがある階層のバイオーム（Biome）によって、釣れるアイテムや生物が異なります。詳細は **[バイオーム・環境システム](Biome-System.md)** とも連動します。

| バイオーム | 釣りポイント | 主な釣獲物 (アイテムID) | 特徴 |
| :--- | :--- | :--- | :--- |
| **洞窟 (Cave)** | 水辺 (`water`) | `fish_cave_salmon` (洞窟鮭), `magic_crystal_shard` (魔力結晶の欠片) | 暗闇での釣り。発光するエサが効果的。 |
| **森林 (Forest)** | 水辺 (`water`) | `fish_slime` (スライムフィッシュ), `apple` (リンゴ) | 最も安全でヒット率が高い。稀に木箱が釣れる。 |
| **氷雪 (Ice)** | 氷穴 (`ice_hole`) | `fish_frozen_cod` (氷結タラ), `ice_crystal` (氷の結晶) | 氷を割る手間が必要だが、回復効果の高い魚が獲れる。 |
| **溶岩 (Lava)** | 溶岩 (`lava`) | `fish_magma_eel` (マグマイール), `obsidian_chunk` (黒曜石の塊), `fire_stone` (火の石) | 溶岩虫が必須。装備素材や耐火資材が釣れる。 |

### 3.2 宝箱・ジャンク・装備品の獲得
魚以外のアイテムがヒットすることもあります。プレイヤーの**運 (Luck)** ステータスが高いほど、以下の貴重品の当選確率が上昇します。
- **沈んだ宝箱 (`wooden_chest`, `iron_chest_locked`)**: 低確率で釣り上がることがあります。開錠には鍵が必要です。詳細は **[宝箱・鍵システム](Chest-Key-System.md)** を参照。
- **錆びた装備品**: 呪われた武器・防具が釣れることがあります。鑑定することで強力な効果が付与されている場合もあります。詳細は **[アイテム識別システム](Item-Identification-System.md)** 参照。
- **ガラクタ (`junk_weed`, `can_empty`)**: ハズレ枠。合成システムの素材としてリサイクル可能です。

## 4. モンスター・派閥との戦闘リスク

### 4.1 奇襲リスク (Ambush)
釣りを行っている最中は、プレイヤーは「待機状態」となり回避率（Evade）が 50% 低下します。
また、水音などのノイズ（Noise）が 3 マス以内に伝播し、周囲の「好戦的（Aggressive）」な野生モンスターを引き寄せる危険があります。

### 4.2 凶暴なモンスターの釣り上げ
釣獲判定時に 5% の確率（釣りポイントの安全度によって変動）で、魚ではなく**水生・溶岩性の野生モンスター**を釣り上げてしまい、即座に戦闘状態（エンカウント）に突入します。
- **釣り上がるモンスターの例**:
  - 森林/洞窟: `kappa` (カッパ), `giant_squid_larva` (ダイオウイカの幼体)
  - 溶岩: `lava_slime` (ラバスライム)
- この方法で出現したモンスターは「釣り上げたプレイヤー」を最優先でターゲット（敵対派閥）と認識します。詳細は **[派閥システム](Faction-System.md)** および **[戦闘システム仕様](Combat-System.md)** を参照。

## 5. 管理者による釣り堀（釣りポイント）の設置とカスタマイズ

ダンジョン管理者（Administrator）は、自らの「マイ・ダンジョン」に、有料または無料の「釣りポイント（`fishing_point`）」を設置して運営できます。

### 5.1 設置コストと仕様
- **施設タイプ**: `'fishing_point'` (設置施設)
- **設置コスト**: `wood` (木材) × 15, `stone` (石材) × 5, 1200 ゴールド
- **消費容量**: **8 容量**
- 詳細は **[施設マスターリスト](Facility-Master-List.md)** および **[建築システム](Construction-System.md)** を参照。

### 5.2 釣り堀のメリット
- **入場誘致**: 釣り堀には野生の水辺より 1.5 倍のレアアイテム・レア魚出現率が設定されるため、探索者（Explorer）の入場を促す強力なコンテンツとなります。
- **利用料収入**: 管理者は釣り堀に「利用料（1キャストごとに数ゴールド）」を設定でき、入場料以外の継続的なゴールド収入源とすることができます。

## 6. 技術仕様・型定義

### 6.1 釣り設定データ (`FishingPointConfig`)
設置された釣り堀施設のカスタマイズデータは、`PlacedFacility` モデル内の `config`（`FishingPointConfig` 型）として管理されます。
```typescript
interface FishingPointConfig {
  fishPoolSize: number;       // 現在の残り魚影数 (上限 10, 時間経過で自然回復)
  allowedBaitTier: number;    // 使用可能なエサの最低/最高 Tier 制限
  usageFee: number;           // 1キャストあたりの利用料（ゴールド、管理者が設定可能）
  bonusMultiplier: number;    // レア出現率補正（標準: 1.0, 施設強化で最大 1.5）
}
```

### 6.2 プレイヤー状態の拡張
プレイヤーの釣りスキル成長要素として、`Player` インターフェースに以下のパラメータを追加します。
- `fishingLevel?: number;` : 釣りスキルレベル（ヒット時間の短縮、タイミング緩和に影響）
- `fishingExp?: number;` : 釣りに成功した際に獲得する熟練経験値
