# Biome-System

## 1. 概要
バイオーム・環境システムは、ダンジョン探索（フロンティア）および管理者によるダンジョン編集（マイ・ダンジョン）において、階層全体を支配する気候、環境、および視覚的テーマ（バイオーム）を定義する仕組みです。
各バイオームは、特有の地形の生成率、出現モンスターや資材ドロップの偏り、およびプレイヤーやモンスターのステータスに対する環境補正を伴い、戦闘やリソース管理の戦略性を大きく向上させます。

## 2. バイオームの種類と特徴
本ゲームでは、以下の 4 つの基本バイオームを定義します。

### 2.1 洞窟バイオーム (Cave Biome)
最も標準的で安定したダンジョン環境です。
- **ID**: `cave`
- **対象階層**: 1F 〜 10F（標準）およびその他の標準フロア
- **ビジュアルテーマ**: 暗茶色の岩肌と土の床。
- **環境効果**: 特殊なバフ・デバフ効果はありません。
- **出現地形**: 床（`.`）、壁（`#`）、扉（`+`）が標準的な比率で生成されます。水、溶岩、砂地などの特殊地形は原則として生成されません（または極めて稀）。

### 2.2 森林バイオーム (Forest Biome)
草木が鬱蒼と生い茂り、生命力に満ちた環境です。
- **ID**: `forest`
- **対象階層**: 11F 〜 30F（標準）
- **ビジュアルテーマ**: 緑色の床、ツタの絡まる木製の壁。
- **環境効果**:
  - **木属性の活性化**: 木（`Wood`）属性を持つすべてのエンティティ（プレイヤー、モンスター、PKer）は、このバイオーム内に滞在している間、**敏捷性（Agility）が 1.1 倍**、および**素早さ（Speed）が 1.1 倍**になります。
  - **火属性の危険**: 火（`Fire`）属性から受けるダメージがすべてのエンティティにおいて **1.1 倍**（通常相性の計算後に乗算）に増加します。
- **出現地形**:
  - 砂地（`:` / 鬱蒼とした茂みとして表現）が床タイルの **10%** の密度でランダムに生成されます。
  - 特殊地形の水（`~`）が低確率で生成されます。
- **ドロップ補正**: `wood` (木材) の基本出現率およびモンスタードロップ率が **1.5 倍** に向上します。

### 2.3 氷雪バイオーム (Ice Biome)
極寒の猛吹雪と永久凍土に包まれた、体温を奪う過酷な環境です。
- **ID**: `ice`
- **対象階層**: 31F 〜 60F（標準）
- **ビジュアルテーマ**: 青白い凍った床、半透明の氷の壁。
- **環境効果**:
  - **水属性の恩恵**: 水（`Water`）属性を持つすべてのエンティティは、このバイオーム内に滞在している間、**防御力（Defense）が 1.15 倍** に向上します。
  - **体温低下デバフ（非水属性）**: 水（`Water`）または火（`Fire`）属性を持たないすべてのエンティティは、極寒による体力の消耗を表現するため、**最大スタミナ（ST）およびHPの自然回復率が半分（0.5 倍）** に低下します。
  - **滑る床（氷床効果）**: 特殊地形の砂地（`:`）は、このバイオームにおいては「氷の床」として扱われます。プレイヤーが氷の床に乗ると、**30% の確率で進行方向に 1 マス余分に滑る** 挙動が発生します。滑る際、追加の行動時間やスタミナは消費されません。
- **出現地形**: 砂地（氷の床）が **15%**、水（凍りかけの湖）が **5%** の密度で生成されます。

### 2.4 溶岩バイオーム (Lava Biome)
灼熱の熱気と溶岩流が渦巻く、一歩のミスが死に直結する超高難易度環境です。
- **ID**: `lava`
- **対象階層**: 61F 〜 99F（標準）
- **ビジュアルテーマ**: 黒い火山岩の床、赤く発光する溶岩壁。
- **環境効果**:
  - **火属性の活性化**: 火（`Fire`）属性を持つすべてのエンティティは、このバイオーム内に滞在している間、**攻撃力（Attack）が 1.15 倍** に向上します。
  - **猛暑デバフ（非火属性）**: 火（`Fire`）または水（`Water`）属性を持たないプレイヤーおよび PKer は、猛暑による水分低下を表現するため、行動（移動・攻撃・アイテム使用など）による **満腹度（Satiety）の消費量が 1.5 倍** に増加します。
  - **溶岩の脅威**: 溶岩（`!`）地形が頻繁に生成されます。
- **出現地形**: 溶岩（`!`）タイルが床タイルの **8%** の密度でランダムに生成されます。

## 3. バイオームと出現・ドロップ補正
ダンジョン内のバイオームは、自然発生するモンスターや採取可能な資材の分布に大きな影響を与えます。

### 3.1 モンスター出現テーブルの重み付け補正
バイオームに対応する属性を持つモンスターは、出現テーブル内の抽選確率（ウェイト）が自動的に **+20% 加算** されます。

- **森林バイオーム**: 木属性モンスター（`goblin`, `orc`, `golem` 等）の出現ウェイトが向上。
- **氷雪バイオーム**: 水属性モンスター（`slime`, `king_slime` 等）の出現ウェイトが向上。
- **溶岩バイオーム**: 火属性モンスター（`dragon` 等）の出現ウェイトが向上。

### 3.2 採取・ドロップ資材の偏り
バイオームに応じて、破壊可能な障害物（木箱、岩等）やモンスター撃破時における特定資材のドロップ確率にボーナスが適用されます。

- **森林バイオーム**: `wood` (木材) のドロップ・採取率が **+15%** 向上。
- **氷雪バイオーム**: `stone` (石材) の代わりに `magic_crystal` (魔力結晶) のドロップ・採取率が **+5%** 向上。
- **溶岩バイオーム**: `magic_stone` (魔力石) および `demon_blood` (魔族の血) のドロップ率が **+5%** 向上（溶岩に隣接した場所でのドロップ確率が累積）。

## 4. データモデルの拡張
バイオーム情報は階層設定（`FloorConfig`）およびダンジョン生成パラメータに組み込まれます。
詳細な仕様は、**[管理者データモデル](../implementation/Admin-Data-Models.md)** および **[ダンジョン生成システム](Dungeon-Generation-System.md)** を参照してください。

### 4.1 FloorConfig へのプロパティ追加
各階層の状態を追記するため、`FloorConfig` に以下のフィールドを追加します。

```typescript
interface FloorConfig {
  floorLevel: number;
  width: number;
  height: number;
  biomeId: 'cave' | 'forest' | 'ice' | 'lava'; // 現在の階層のバイオームID
  tiles: string[][];
  monsters: PlacedMonster[];
  traps: PlacedTrap[];
  shops: PlacedShop[];
  facilities: PlacedFacility[];
}
```

### 4.2 マイ・ダンジョン編集時のバイオーム選択
管理者は「マイ・ダンジョン」を編集する際、ゴールドおよび特定資材を支払うことで、各階層のバイオームを自由に変更することができます。
- **バイオーム変更コスト**:
  - `cave` → `forest`: 2,000 G + `wood` × 50
  - `cave` → `ice`: 5,000 G + `magic_crystal` × 20
  - `cave` → `lava`: 8,000 G + `demon_blood` × 10
