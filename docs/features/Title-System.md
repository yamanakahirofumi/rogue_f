# Title-System

## 1. 概要
称号・実績システム（Title & Achievement System）は、プレイヤーがゲーム内で達成した特定の業績（実績）を「称号」として獲得・装備し、マルチプレイヤー環境での個性表示や、探索・経営における微小な恩恵（バフ）を得るための仕組みです。
このシステムは、プレイヤーが「探索者」「管理者」「PKer」の各役割において長期的な目標（やり込み要素）を持つことを可能にし、世界観の深掘りやマルチプレイ時の競争・協調を促進します。

## 2. 称号の獲得（実績の解除条件）
称号は、各役割や特定の活動でのマイルストーンを達成した際に自動的にアンロック（解放）されます。

### 2.1 探索者（Explorer）向け称号
ダンジョン「フロンティア」の攻略やプレイヤーとしての戦闘、生存に関する実績です。

- **新米探索者** (`rookie_explorer`):
  - **解除条件**: フロンティアで **5F** に到達する。
  - **効果**: 最大HP +5。
- **深淵の探究者** (`deep_abyss_diver`):
  - **解除条件**: フロンティアで **50F** に到達する。
  - **効果**: 視野半径が 1 マス拡張される。詳細は [視界システム](Visibility-System.md) 参照。
- **不屈の生存者** (`indomitable_survivor`):
  - **解除条件**: HP が 10% 以下の絶体絶命の状態から、無事に拠点（Base）に帰還する。
  - **効果**: 自然回復が発生した際、スタミナ（ST）の回復量が常に **+1** される。
- **トラップデストロイヤー** (`trap_destroyer`):
  - **解除条件**: 累計で **100 回** トラップの解除に成功する。
  - **効果**: トラップ解除の成功率が **+10%** 向上する。詳細は [トラップシステム](Trap-System.md) 参照。

### 2.2 管理者（Administrator）向け称号
モンスターの飼育、繁殖、および「マイ・ダンジョン」の運営・建築に関する実績です。

- **新米ブリーダー** (`novice_breeder`):
  - **解除条件**: モンスターの卵を累計 **5 回** 孵化させる。
  - **効果**: モンスター繁殖時の孵化時間が **10% 短縮** される。詳細は [モンスター繁殖システム](Monster-Breeding-System.md) 参照。
- **遺伝子の支配者** (`gene_master`):
  - **解除条件**: 3つ以上の特性、または Epic レアリティの特性を持つモンスターを繁殖で誕生させる。
  - **効果**: 繁殖時の「特性突然変異率」および「属性突然変異率」が **+2%** 増加する。
- **キルゾーン構築家** (`killzone_architect`):
  - **解除条件**: 自身のマイ・ダンジョンで、侵入者（Explorer/PKer）を累計 **30 体** 撃破（ロスト）させる。
  - **効果**: [彫像システム](Statue-System.md)の「強欲の彫像」の効果範囲内で得られる管理者の獲得ゴールドボーナスがさらに **+5%**（計 1.25 倍）に強化される。
- **豪商** (`wealthy_merchant`):
  - **解除条件**: マイ・ダンジョン内のショップで、累計 **100,000 ゴールド** の売上を達成する。
  - **効果**: 管理者ショップでのアイテム仕入れコスト（卸売価格）が **5% 割引** される。詳細は [ショップシステム](Shop-System.md) 参照。

### 2.3 侵入者・PKer（Invader）向け称号
他者の「マイ・ダンジョン」への乱入（PK）に関する実績です。

- **シャドウランナー** (`shadow_runner`):
  - **解除条件**: PK乱入に累計 **5 回** 成功し、生存したまま生還する。
  - **効果**: 「Stray（野良）」モードでの乱入時、移動時の消費スタミナ（ST）が **10% 軽減** される。詳細は [PKシステム](PK-System.md) 参照。
- **災厄の獣** (`calamity_beast`):
  - **解除条件**: モンスター形態でプレイヤーを累計 **20 体** 撃破する。
  - **効果**: 乱入時の最大 ST が **+5** され、攻撃力が **1.05 倍** になる。

### 2.4 特別・ストーリー（Special & Story）称号
ストーリーの進行や特別な活動で得られる称号です。

- **歴史の目撃者** (`history_witness`):
  - **解除条件**: [ストーリー・世界観システム](Story-Lore-System.md) の Lore Record（ロア記録）を **15 個以上** 解放する。
  - **効果**: 拠点の一部のNPCとの会話で、特別なダイアログが選択可能になる。
- **トラストネットワークの架け橋** (`trust_bridge`):
  - **解除条件**: 他の管理者のサーバーとの間で、累計 **10 回** キャラクターやモンスターの持ち込み（マイグレーション）を行う。
  - **効果**: サーバー移動時の手数料が無料になる、または移動先での初期ゴールドにボーナスが付与される。詳細は [機能仕様書](Functional-Specification.md) 参照。

## 3. 称号の装備と効果適用ルール

### 3.1 装備の制限
- プレイヤーは獲得した称号の中から、**最大 1 つ** を「アクティブな称号（`activeTitleId`）」として装備することができます。
- 未獲得の称号を装備することはできません。

### 3.2 恩恵の適用
- 称号によるステータス補正や特殊効果（バフ）は、**その称号を装備（アクティブに）している間のみ** 有効化されます。
- 獲得しているだけで装備していない称号のバフ効果は適用されません。これにより、「効果目的で特定の称号を装備する」か、「純粋な名誉表示として好みの称号を装備する」かといったプレイヤーの選択肢が生まれます。

### 3.3 表示と名誉要素
- マルチプレイヤー環境において、装備中の称号はプレイヤー名の上部、または前後にブラケット（例: `[深淵の探究者] PlayerName`）として常時表示されます。
- [ランキングシステム](Ranking-System.md) のランキングボード上でも、アクティブな称号が名前とともに掲載されます。

## 4. NPCダイアログとの動的連携
装備している称号は、拠点のNPC商人や案内人との親密度、および会話内容に影響を与えます。

- **ダイアログ変化**: 特定の称号（例: `[遺伝子の支配者]` や `[不屈の生存者]`）を装備した状態でNPCに話しかけると、その実績を称えるセリフや、特別なヒント、追加の取引メニューが解放されることがあります。
- **親密度の加速**: 称号の種類に応じて、関連するNPCとの会話時における親密度の獲得効率が **1.2 倍** になるなどの恩恵があります。

## 5. UI・UX 仕様

### 5.1 称号・実績管理メニュー
プレイヤーは、拠点（Base）のパーソナルメニューから「称号・実績（Titles & Achievements）」画面にアクセスできます。

- **実績一覧リスト**: すべての称号と、そのアンロック条件、および現在のアクティブ効果が一覧表示されます。
  - **解放済み**: カラーで表示され、右側に「装備する」ボタンが表示されます（現在装備中のものは「装備中」とハイライトされます）。
  - **未解放**: グレーアウトされ、解放条件（例: `フロンティア50Fに到達する (現在: 32F)`）が進行度バーとともに表示されます。
- **アクティブ表示**: 画面上部には、現在のキャラクターの全身図と装備中の称号プレビューが大きく表示されます。

## 6. 技術データ構造 (Technical Data Structures)
称号および実績情報の管理、装備状態の保存に必要なデータ定義です。

### 6.1 Playerデータモデルの拡張
プレイヤーの称号所持状態およびアクティブな称号を管理するため、**[Playerデータモデル](../../src/@types/player.d.ts)** に以下のプロパティを追加します。

```typescript
// Playerクラス/インターフェースに追加されるプロパティ
unlockedTitleIds?: string[];  // アンロックされた称号のIDリスト
activeTitleId?: string;       // 現在装備中の称号のID (未装備時は undefined または空文字)
```

### 6.2 TitleEntry（称号エントリー）インターフェース
称号のメタデータを定義する構造です。

```typescript
interface TitleEntry {
  id: string;                                                 // ユニークID (例: 'deep_abyss_diver')
  name: string;                                               // 称号名 (例: '深淵の探究者')
  description: string;                                        // 実績解除の条件説明
  effectDescription: string;                                  // 特殊効果の説明
  category: 'explorer' | 'admin' | 'pker' | 'special';        // カテゴリ分類
  unlockCondition: {
    type: 'max_floor' | 'breed_count' | 'pk_wins' | 'lore_count' | 'gold_spent'; // 解除トリガー種別
    value: number;                                            // 必要閾値
  };
  unlockedAt?: Date;                                          // 解放日時 (未解放時は undefined)
}
```

## 7. 称号マスターリスト (Title Master List)
実装およびマスターデータ構築の基礎となる全12種類の称号の完全定義一覧です。各称号の解除条件パラメータ、装備時のシステム補正効果、およびゲームエンジン内での処理フック（フックタイミング）を定めます。

| 称号ID | 称号名 | カテゴリ | 解除トリガー | 必要閾値 | 装備効果（バフ詳細） | 処理フック (`hookTrigger`) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `rookie_explorer` | 新米探索者 | `explorer` | `max_floor` | 5 | 最大HP +5 | `on_stat_calc` |
| `deep_abyss_diver` | 深淵の探究者 | `explorer` | `max_floor` | 50 | 視野半径 +1マス | `on_visibility_calc` |
| `indomitable_survivor` | 不屈の生存者 | `explorer` | `low_hp_escape` | 1 | 自然回復時のST回復量 +1 | `on_stamina_recovery` |
| `trap_destroyer` | トラップデストロイヤー | `explorer` | `trap_disarm_count` | 100 | トラップ解除成功率 +10% | `on_trap_disarm` |
| `novice_breeder` | 新米ブリーダー | `admin` | `breed_count` | 5 | モンスター孵化時間 10%短縮 | `on_hatch_duration` |
| `gene_master` | 遺伝子の支配者 | `admin` | `epic_trait_breed` | 1 | 繁殖時突然変異率 +2% | `on_mutation_check` |
| `killzone_architect` | キルゾーン構築家 | `admin` | `dungeon_kill_count` | 30 | 強欲の彫像ゴールドボーナス +5% (計1.25倍) | `on_gold_bonus` |
| `wealthy_merchant` | 豪商 | `admin` | `gold_spent` | 100000 | 管理者ショップ仕入れ値 5%割引 | `on_shop_buy` |
| `shadow_runner` | シャドウランナー | `pker` | `pk_escape_count` | 5 | 野良(Stray)モード移動時消費ST 10%軽減 | `on_stamina_cost` |
| `calamity_beast` | 災厄の獣 | `pker` | `pk_wins` | 20 | モンスター形態最大ST +5、攻撃力1.05倍 | `on_stat_calc` |
| `history_witness` | 歴史の目撃者 | `special` | `lore_count` | 15 | 拠点特定NPCの限定ダイアログ解放・親密獲得1.2倍 | `on_npc_dialog` |
| `trust_bridge` | トラストネットワークの架け橋 | `special` | `migration_count` | 10 | サーバー間キャラ/モンスター移動手数料無料 | `on_migration` |

### 7.1 各処理フックの実行詳細
- **`on_stat_calc`**: プレイヤーまたはPKerのステータス計算処理実行時に呼び出され、最大HP/STや攻撃倍率を動的に加算・乗算補正します。
- **`on_visibility_calc`**: 階層開始時および照明計算時に呼び出され、基本視界半径（視界システム参照）を拡張します。
- **`on_stamina_recovery`**: 10秒毎の自然回復処理（自然回復システム参照）において、ST回復基礎値に定数を直接加算します。
- **`on_trap_disarm`**: プレイヤーがトラップ解除コマンドを実行した際、最終成功確率計算式に +10% を加算します。
- **`on_hatch_duration`**: モンスター卵生成時に必要孵化時間を `hatchTimeTotal * 0.90` に減算設定します。
- **`on_mutation_check`**: モンスター交配時の遺伝判定ロジックにおいて、特性・属性突然変異判定フラグを +2.0% 嵩上げします。
- **`on_gold_bonus`**: 自ダンジョン内で「強欲の彫像」効果範囲内にてプレイヤー撃破/ドロップが発生した際、ゴールド倍率を 1.20 から 1.25 に上書きします。
- **`on_shop_buy`**: 管理者による商品仕入れ/補充処理実行時に、卸売コストを 0.95 倍に適用します。
- **`on_stamina_cost`**: PKerが「Stray」モードで移動コマンドを実行した際、移動コストを `cost * 0.90` に計算します。
- **`on_npc_dialog`**: 拠点NPCとの会話トリガー検知時、条件一致フラグを解放し親密度加算値を 1.2 倍にします。
- **`on_migration`**: 他サーバーとの信頼ネットワーク間移行時、移行手数料徴収処理をスキップします。
