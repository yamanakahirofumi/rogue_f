# Equipment-System

## 1. 概要
装備システムは、プレイヤーが武器、防具、装飾品を身に着けることでステータスを強化し、ダンジョン探索や戦闘を有利に進めるための仕組みです。インベントリ内のアイテムを「装備」することで、そのアイテムが持つ補正値がプレイヤーの能力に反映されます。

## 2. 装備スロット
プレイヤーは以下のスロットに、それぞれ 1 つずつアイテムを装備できます。

- **武器 (Weapon)**: 主に攻撃力を上昇させます。
- **防具 (Armor)**: 主に防御力を上昇させます。
- **装飾品 (Accessory)**: 攻撃力、防御力、敏捷性、器用さ、素早さ、運など、様々なステータスを補助します。

## 3. 装備のルール

### 3.1 装備 (Equip)
- インベントリ内にある `subType` が `weapon`, `armor`, `accessory` のいずれかであるアイテムを選択し、「装備する」アクションを行うことで装備状態になります。
- 既に同じスロットに他のアイテムを装備している場合、自動的に古い装備が外され（インベントリに戻り）、新しいアイテムが装備されます。
- **処理レスポンス (`EquipResult`)**: 装着されたアイテムID、スロット種別、自動的に取り外された以前の装備品ID (`unequippedItemId`)、および呪い状態フラグ (`isCursed`) が返却されます（[実装詳細](../implementation/Implementation-Details.md) 参照）。

### 3.2 装備解除 (Unequip)
- 現在装備しているアイテムを選択し、「外す」アクションを行うことで装備を解除できます。
- 解除されたアイテムはインベントリに戻ります。インベントリが満杯の場合、装備を外すことはできません。
- **処理レスポンス (`UnequipResult`)**: 取り外されたアイテムIDとスロット種別が返却されます（[実装詳細](../implementation/Implementation-Details.md) 参照）。

### 3.3 呪いと装備 (Curses)
- [アイテム識別システム](Item-Identification-System.md) に基づき、呪われた（`isCursed: true`）装備品を装備すると、通常の「外す」アクションが使用不能になります。
- 呪いを解く（解呪の巻物などを使用する）か、特定のイベントが発生しない限り、その装備を固定されます。

## 4. ステータスへの影響
装備品は装着中、以下のプレイヤーパラメータ（[Playerデータモデル](../implementation/Implementation-Details.md) 参照）に補正を加えます。

- **攻撃力 (attack)**: 武器および一部の装飾品によって加算されます。
- **防御力 (defense)**: 防具および一部の装飾品によって加算されます。
- **敏捷性 (agility)**: [戦闘システム](Combat-System.md) における攻撃インターバルを短縮します。
- **器用さ (dexterity)**: 命中率を向上させます。
- **素早さ (speed)**: 回避率を向上させます。
- **運 (luck)**: 一部の装飾品によって加算され、クリティカル率、トラップ発見・解除成功率、宝箱解錠率、ドロップ獲得率、および合成成功率を向上させます。
- **属性 (attribute)**: 武器や防具に付与されている属性（`Fire`, `Water`, `Wood`, `Light`, `Dark`）。武器属性は敵属性との相性によるダメージ倍率計算に寄与し、防具属性は敵の属性攻撃に対する軽減や環境デバフの耐性に影響します（詳細は [属性システム](Attribute-System.md) を参照）。
- **特殊効果・追加効果**: 装備品固有の追加パラメータおよびパッシブ効果。
  - 状態異常付与（例: 「毒の短剣」による攻撃時 **20%** の確率での「毒」付与）
  - ダメージ軽減（例: 「魔法のローブ」による全属性ダメージ **10%** 軽減）
  - 攻撃射程 (`range`): 近接（1マス）または遠距離（弓等）の攻撃到達距離
  - 投擲威力 (`throwAttack`): アイテム投擲時の攻撃ダメージ計算補正

補正の計算例:
`現在の攻撃力 = プレイヤーの基本攻撃力 + 装備中の武器の補正値 + 装備中の装飾品の補正値`
`現在の運 = プレイヤーの基本運 + 装備中の装飾品の補正値`

## 5. データモデルとの関連
本システムは `InventoryItem` インターフェースの拡張によって管理されます。

### 5.1 装備品に必要なプロパティ
`InventoryItem` に以下の追加情報を（メタデータとして）保持することを想定します。

- `subType`: `weapon`, `armor`, `accessory`
- `enhanceLevel`: 装備強化値 (+0〜+10)
- `attackBonus`: 攻撃力補正値
- `defenseBonus`: 防御力補正値
- `agilityBonus`: 敏捷性補正値
- `dexterityBonus`: 器用さ補正値
- `speedBonus`: 素早さ補正値
- `luckBonus`: 運補正値
- `attribute`: 属性 (`'Fire'`, `'Water'`, `'Wood'`, `'Light'`, `'Dark'`, `'None'`)
- `range`: 攻撃射程（未設定時は 1）
- `throwAttack`: 投擲威力

### 5.2 プレイヤーの状態
`Player` オブジェクトには、現在装備中のアイテムの ID を保持する以下のフィールドが含まれます。
- `weaponId`: 装備中の武器の ID
- `armorId`: 装備中の防具の ID
- `accessoryId`: 装備中の装飾品の ID

## 6. 装備強化・祝福・解呪システム

### 6.1 装備強化 (Equipment Enhancement)
武器および防具は、対応する強化の巻物（`scroll_enhance_weapon`, `scroll_enhance_armor`）を使用することで強化値（`enhanceLevel`）を付与・上昇させることができます。

- **最大強化値**: **+10**。
- **ステータス上昇ルール**:
  - 武器: 強化値（`enhanceLevel`）1 ごとに `attackBonus` が **+1** 増加。
  - 防具: 強化値（`enhanceLevel`）1 ごとに `defenseBonus` が **+1** 増加。
- **強化成功確率**:
  - **+0 → +3**: **100%**
  - **+3 → +6**: **80%**
  - **+6 → +9**: **50%**
  - **+9 → +10**: **25%**
- **失敗時ペナルティ**:
  - **+0 〜 +6 での失敗**: アイテムの強化値は変化せず、巻物のみが消費されます。
  - **+7 以上での失敗**: 失敗時に強化値（`enhanceLevel`）が **1 低下** します。
- **祝福の相乗効果**:
  - 祝福状態の装備品（`isBlessed: true`）または「祝福された強化の巻物」を使用した場合、成功確率に **+10%** のボーナスが加算され、さらに失敗時の強化値低下ペナルティが発生しません。
- **呪いの制限**:
  - 呪われている装備品（`isCursed: true`）は、解呪するまで強化の巻物の対象に指定できません。

### 6.2 解呪 (Uncursing)
- 「解呪の巻物 (`scroll_uncurse`)」を使用することで、装備中またはインベントリ内の呪われたアイテム（`isCursed: true`）を通常状態（`isCursed: false`）へ戻すことができます。
- 呪いが解かれた装備品は即座に外すことが可能になります。

### 6.3 祝福 (Blessing)
- 「祝福の巻物 (`scroll_blessing`)」を使用することで、対象の装備品に祝福状態（`isBlessed: true`）を付与できます。
- 祝福された装備品は基本攻撃力/防御力補正に固定で **+1** のボーナスが与えられ、強化時の成功率向上および保護効果を得ます。
