# Emote-Stamp-Master-List

## 1. 概要
本ドキュメントでは、RogueF におけるプレイヤーおよび PKer が使用可能なエモート（定型文）とスタンプ（記号）のマスターリストを定義します。これらは、自由入力チャットに代わるコミュニケーション手段として機能します。

## 2. エモート (Emotes)
テキスト形式の定型文です。メッセージログおよびキャラクターの頭上に表示されます。

| ID | 表示テキスト | カテゴリ | 備考 |
| :--- | :--- | :--- | :--- |
| `greet_hello` | こんにちは！ | 挨拶 | 汎用的な挨拶。 |
| `greet_nice_to_meet` | よろしく！ | 挨拶 | |
| `combat_ready` | いざ勝負！ | 戦闘 | 戦闘開始時の宣言。 |
| `combat_yield` | 降参だ…… | 戦闘 | |
| `combat_victory` | 勝利！ | 戦闘 | |
| `social_thanks` | ありがとう！ | 社交 | |
| `social_sorry` | ごめん。 | 社交 | |
| `pker_stray` | 私はただの野良モンスターだ。 | PK専用 | 正体を隠す（？）ための言葉。 |
| `pker_threat` | 逃がさないぞ…… | PK専用 | |

## 3. スタンプ (Stamps)
記号やアイコンを用いた視覚的な表現です。キャラクターの頭上にポップアップで表示されます。

| ID | 表示記号 | 意味 | 備考 |
| :--- | :--- | :--- | :--- |
| `stamp_exclamation` | `(!)` | 驚き・発見 | |
| `stamp_question` | `(?)` | 疑問・混乱 | |
| `stamp_heart` | `<3` | 好意・感謝 | |
| `stamp_angry` | `(怒)` | 怒り | |
| `stamp_sweat` | `(;^ω^)` | 焦り | |
| `stamp_v` | `(v)` | 勝利・ピース | |

## 4. 技術的仕様
- **表示時間**: エモートおよびスタンプは、発信後 **3 秒間** キャラクターの頭上に表示されます。
- **クールタイム**: 連続送信によるスパムを防止するため、一度使用すると **2 秒間** は次のエモート・スタンプを送信できません。
- **ログへの記録**: エモートのみ、メッセージログに「[名前]: [テキスト]」の形式で記録されます。
