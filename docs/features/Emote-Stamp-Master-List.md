# Emote-Stamp-Master-List

## 1. 概要
エモートおよびスタンプシステムは、プレイヤー（探索者）と PKer（乱入者）がダンジョン内で意思疎通を図るための簡易コミュニケーションツールです。世界観を損なわない範囲での交流や煽り、あるいは協力の意思表示を可能にします。

## 2. 基本仕様

### 2.1 表示と持続時間
- **表示形式**:
    - **エモート (Emotes)**: キャラクターの頭上に吹き出し形式でテキストが表示されます。
    - **スタンプ (Stamps)**: キャラクターの頭上に特定のアイコン画像（スプライト）が表示されます。
- **持続時間**: 実行から **3 秒間** 表示され、その後自動的に消滅します。
- **ログへの記録**: 実行されたエモートのテキスト内容は、メッセージログ（Message Component）にも一定期間記録されます。

### 2.2 クールダウン (Cooldown)
- **制限**: 連続した使用による画面の占有を防止するため、一度使用すると **2 秒間** のクールダウンが発生します。
- クールダウン中は、新たなエモートやスタンプの実行コマンドは受理されません。

### 2.3 API エンドポイント
- **送信**: `PUT /api/player/{userId}/emote/{emoteId}`
- **リクエスト**: `EmoteSendRequest` (必要に応じて任意パラメータ)
- **レスポンス**: `EmoteSendResult` (`success`, `cooldownRemainingSeconds`, `message`)
- この API を通じて、サーバーへエモートまたはスタンプの実行を通知します。

### 2.4 リアルタイム配信と視界ルール (SSE Broadcast)
- **リアルタイム配信**: プレイヤーや PKer が送信したエモートおよびスタンプは、サーバーを通じて同じフロアに滞在する他プレイヤーへ SSE (`GET /api/fields/{userId}`) ストリーム経由で即座に一斉配信（ブロードキャスト）されます。
- **配信データ構造 (`EmoteStampBroadcastEvent`)**:
  - `speakerUserId`: 発言者のユーザーID
  - `speakerName`: 表示名（プレイヤー名またはモンスター種別名）
  - `speakerRole`: 発言者の役割 (`'explorer'` | `'admin'` | `'pker'`)
  - `targetType`: 種別 (`'emote'` | `'stamp'`)
  - `emoteOrStampId`: 対象のエモートIDまたはスタンプID
  - `textOrSymbol`: 描画テキストまたは表示用シンボルマーク
  - `position`: 実行時のマップ座標 (`{ x, y }`)
  - `timestamp`: 発生時刻 (UNIX ms)
- **視界制限 (Fog of War)**: 受信クライアントの現在視界内（[視界システム](Visibility-System.md) 参照）で発生したエモート・スタンプのみがゲーム画面上に頭上吹き出し/アイコンとして 3 秒間描画されます。視界外での発言は画面上には表示されず、メッセージログへのみ記録されます（観戦モード等の全開視界時は常に表示）。

### 2.5 特殊スタンプのアンロックと所持
- **基本スタンプ**: 全プレイヤーが初期状態から利用可能な標準スタンプ群です。
- **報酬・実績スタンプ (Custom Stamps)**: クエスト達成（[クエストシステム](Quest-System.md) の `QuestEntry.rewards.customStampId` 参照）、称号・実績解除、シーズンランキング報酬などによってアンロックされます。
- **所持状態の保持**: 解放された特殊スタンプの ID リストは `Player` モデルの `unlockedStampIds: string[]` プロパティに保持され、UI パレット（[UI・UX設計](UI-UX-Design.md) 参照）で選択・送信可能になります。

## 3. エモートリスト (Emotes)

テキストベースの簡易定型文です。

| ID | 表示テキスト | 意図・用途 |
| :--- | :--- | :--- |
| `greet` | こんにちは！ | 挨拶 |
| `thanks` | ありがとう！ | 感謝 |
| `sorry` | ごめんなさい | 謝罪 |
| `help` | 助けて！ | 救援要請 |
| `watch_out` | 気をつけて！ | 警告 |
| `nice` | いいね！ | 賞賛 |
| `bye` | さようなら | 別れ |

## 4. スタンプリスト (Stamps)

視覚的なアイコンによるコミュニケーションです。

### 4.1 基本スタンプ (Basic Stamps)
初期状態で全プレイヤーが利用可能なスタンプです。

| ID | アイコンイメージ | 意図・用途 |
| :--- | :--- | :--- |
| `stamp_heart` | ❤️ | 好意・感謝 |
| `stamp_exclamation` | ❗ | 驚き・注目 |
| `stamp_question` | ❓ | 疑問 |
| `stamp_angry` | 💢 | 怒り |
| `stamp_sweat` | 💦 | 焦り・困惑 |
| `stamp_skull` | 💀 | 警告・死 |
| `stamp_check` | ✅ | 同意・確認 |

### 4.2 報酬・実績スタンプ (Custom Reward Stamps)
クエスト、称号、ランキング報酬などでアンロックされる限定スタンプです。アンロック後、`Player.unlockedStampIds` に保存されます。

| ID | アイコンイメージ | アンロック条件 / 入手経路 | 意図・用途 |
| :--- | :--- | :--- | :--- |
| `stamp_crown` | 👑 | 深階層踏破・ランキング1位達成 | 覇者・達成の誇り |
| `stamp_trophy` | 🏆 | クエストコンプリート実績達成 | 成果・トロフィー獲得 |
| `stamp_fire` | 🔥 | PK連続勝利・ボス討伐 | 闘志・激闘の証明 |
| `stamp_thumbs_up` | 👍 | 観戦応援・ギルド推薦クエスト | 賛辞・グッジョブ |
| `stamp_poop` | 💩 | ミミック遭遇・トラップ発動 | トホホ・失敗談 |
| `stamp_star` | ⭐ | 拠点神殿祈願・特別イベント | 祝福・スター到達 |
| `stamp_skull_gold` | 💀✨ | 殿堂入りPKer・深淵最深部到達 | 究極の威嚇・栄誉 |

## 5. モンスター形態（PKer）での利用
- PKer として乱入しているプレイヤーも、これらのエモートおよびスタンプを自由に使用できます。
- モンスターが人語を解さない設定であっても、システム上のエモートとして他プレイヤーに可視化されます。
