# UI-UX-Design

## 1. 画面構成とルーティング
アプリケーションは以下のルートで構成されています。

- `/user/create`: **ユーザー作成画面**
  - 新規プレイヤーの作成を行います。
- `/play`: **プレイ画面**
  - ダンジョン探索のメイン画面です。
- `/admin`: **管理画面**
  - 世界設定、アイテム設定、メニュー管理などを行います。
  - `/admin/menu`: 管理メニューを表示します。
  - `/admin/menu/menu`: 世界設定（`WorldComponent`）を表示します（子ルート）。

## 2. コンポーネント階層
主なコンポーネントの階層構造は以下の通りです。

- `AppComponent`
  - `CreateUserComponent` (ユーザー作成)
  - `DungeonComponent` (プレイ画面)
    - `MessageComponent` (メッセージ表示)
    - `StatusBarComponent` (ステータス表示)
    - **昼夜・天候インジケーター** (時間帯・天候・環境デバフのHUD表示)
    - **エモート・スタンプパレット** (意思疎通ツールの選択パネル)
    - **宝箱操作モーダル** (開錠・解錠・破砕・鑑定の選択UI)
    - **釣り操作パネル** (釣竿・エサ選択およびヒットミニゲームUI)
    - **祭壇・彫像相互作用ダイアログ** (祈願・捧げ物・冒涜・彫像効果確認UI)
    - **クエスト・実績・称号管理ウィンドウ** (進行中クエスト・称号付け替え・実績参照UI)
    - **モンスター図鑑ウィンドウ** (解析レベル・遭遇数・捕獲数・図鑑ボーナス閲覧UI)
  - `AdminModule` (遅延読み込み)
    - `MenuComponent` (管理メニュー)
      - `WorldComponent` (世界設定、子ルートとして表示)
      - **施設配置パネル** (彫像、祭壇、釣り堀等のD&D/クリック設置UI)
      - **遠征隊編成・管理パネル** (所有モンスターの遠征派遣・進捗・報酬受取UI)

## 3. 基本デザイン

### 3.1 基本カラーと操作フィードバック
- **背景色**: 黒 (`background: black`)
- **文字色**: 白 (`color: white`)
- **フォント**: `"Courier New"`, `"Noto Sans Mono CJK"`, monospace (ローグライクらしいレトロな雰囲気を演出)
- **操作フィードバック**:
  - ゲーム内メッセージ（`MessageComponent`）によるイベントログ出力。
  - ステータスバー（`StatusBarComponent`）によるリアルタイムな状態表示。
    - **HP/スタミナ**: プログレスバーで視覚的に表示。
    - **満腹度**: アイコンの色変化や数値で空腹状態を警告。
    - **状態異常**: 付与されているバフ・デバフのアイコンを表示し、ホバーで詳細を確認可能。

### 3.2 昼夜・天候インジケーター (HUD Widget)
プレイ画面の上部HUDエリアに常時表示される時間帯および天候の表示ウィジェットです。
- **表示内容**:
  - **時間帯**: 昼（太陽アイコン / 黄色テキスト `DAY`）または夜（月アイコン / 紫青色テキスト `NIGHT`）。120ティック周期の残り時間をプログレスバーまたはゲージで表示。
  - **天候**: 快晴 (`clear`)、降雨 (`rain`)、濃霧 (`fog`)、吹雪 (`blizzard`)、猛暑 (`heatwave`) のアイコン表示。
  - **環境異常警告**: 吹雪時の冷気（`CHILLED`）、猛暑時の熱気（`OVERHEATED`）などの環境補正デバフ発生時に警告フレームを点滅表示。

### 3.3 エモート・スタンプパレット (HUD Widget)
他の探索者やPKerとの簡便なコミュニケーションを行うための送信パレットです。
- **表示・操作仕様**:
  - ショートカットキー（例: `E` キー）またはHUD上の専用アイコンクリックでパレット展開。
  - テキストエモート（挨拶、感謝、警告等）とアスキーアート/画像スタンプのタブ切替表示。
  - 選択実行時、使用者の頭上（フィールドマップ上）に 3 秒間ポップアップ表示。
  - 連続連打を防止するため、実行後 2 秒間のクールダウンゲージを表示。

## 4. ミニマップ機能 (Mini-map)
探索済みのエリアと現在位置を把握するための補助的な UI です。

### 4.1 表示仕様
- **配置**: プレイ画面（`/play`）の右上または右下にオーバーレイ表示。
- **サイズ**: ダンジョン全体の約 1/4 〜 1/6 程度の縮尺、または周囲 15x15 マス程度の固定サイズ（切り替え可能）。
- **透過度**: 背景が透けて見えるよう適度なアルファ値を設定。

### 4.2 描画要素
- **壁 (Wall)**: 灰色または暗い色で描画。
- **通路・部屋 (Floor)**: 明るい灰色または白で描画（探索済みの場所のみ）。
- **プレイヤー (Player)**: 黄色または白色の点（現在位置）。
- **階段 (Stairs)**: 下り階段は青、上り階段は緑のアイコンまたは点で表示（発見済みの場合のみ）。
- **ショップ (Shop)**: ドルのアイコンまたは特定の記号 (`$`) で表示（発見済みの場合のみ）。
- **扉 (Door)**: 茶色またはオレンジ色の点 (`+`) で表示。
- **回復の泉 (Recovery Spring)**: 水色の点 (`&`) で表示。
- **転送門 (Teleport Gate)**: 紫色の点 (`O`) で表示。
- **トラップ (Trap)**: 赤色の点 (`^`) で表示（発見済みの場合のみ）。
- **宝箱 (Chest)**: 金色または黄色の点 (`C`) で表示（発見済みの場合のみ）。
- **釣り堀 (Fishing Point)**: シアン色または水色の点 (`F`) で表示（発見済みの場合のみ）。
- **祭壇 (Altar)**: 紫色または白色の点 (`A`) で表示（発見済みの場合のみ）。
- **彫像 (Statue)**: 橙色または銀色の点 (`S`) で表示（発見済みの場合のみ）。

### 4.3 フォグ・オブ・ウォー (Fog of War)
- 未探索のエリアはミニマップ上では完全に黒く（非表示）なります。
- プレイヤーが移動することで、その周囲の視界が確保され、ミニマップが徐々に更新されます。

## 5. 探索者用インタラクティブ機能 UI 仕様

### 5.1 宝箱・鍵操作モーダル
宝箱（木、鉄、魔法、ミミック）に隣接または足元でインタラクトした際に表示される操作モーダルです。
- **アクション選択肢**:
  - **手で開ける（ピッキング）**: 器用さ（Dexterity）に基づく成功率を表示。
  - **鍵を使用して開ける**: インベントリ内の所持鍵（鉄の鍵、魔法の鍵等）をドロップダウンから選択して消費開錠。
  - **物理破壊（強撃）**: 武器の攻撃力による破壊試行。アイテム損壊リスク（%）と罠発動確率を警告表示。
  - **鑑定/見破り**: 運（Luck）や特定スキルによるミミック判別・罠有無の検査。
- **結果表示**:
  - 開封成功時: ドロップアイテムのカード表示とインベントリ格納ダイアログ。
  - 失敗/開錠不可時: エラーメッセージと解錠ツール損傷フィードバック。
  - 罠発動/ミミック覚醒時: 赤色フラッシュ演出と戦闘状態/状態異常付与ログ。

### 5.2 釣り操作パネル
水辺、溶岩、または管理者設置の「釣り堀」に隣接して釣りコマンドを開始した際に表示されるアクションパネルです。
- **準備画面**:
  - **釣竿選択**: 所持インベントリ内の釣竿 (`rod_wood`, `rod_iron`, `rod_magic`) を選択。
  - **エサ選択**: インベントリ内のエサ (`bait_worm`, `bait_glowing`, `bait_lava_worm` 等) を選択。なしでの試行も可能。
- **実効画面 (ミニゲーム/タイミングゲージ)**:
  - キャスト後の待機ゲージおよびウキの振動演出。
  - 「HIT!」発生時のタイミング押しボタン（タイミング精度により釣獲確率が変動）。
- **結果画面**:
  - 釣獲成功: 釣り上げた魚・資材の獲得通知と釣り熟練度（経験値）の上昇プログレス表示。
  - 失敗/ミス: エサ消費と失敗ログ。
  - モンスター襲撃 (`monster_ambush`): 水中・溶岩モンスター出現の警告ダイアログと戦闘フェーズへの切り替え。

### 5.3 祭壇・彫像相互作用ダイアログ
- **祭壇ダイアログ**:
  - 四大神（アレス、アテナ、デメテル、フォルトゥナ）のグラフィック/シンボルと神性を表示。
  - アクションボタン: 「祈る」「ゴールド献上」「アイテム献上」「冒涜/略奪（PKer専用/リスク大）」。
  - 神の加護（`DIVINE_BLESSING`）獲得時の黄金カットイン演出、または神罰（`DIVINE_PUNISHMENT`）発生時の暗雲カットイン演出。
- **彫像ダイアログ**:
  - 探索者視点: 設置された彫像のタイプ（威圧, 守護, 治癒, 強欲, 発光）と有効効果範囲のハイライト表示。
  - 管理者視点: 配置済み彫像の効果タイプの変更・選択ドロップダウンと撤去ボタン。

### 5.4 クエスト・実績・称号管理ウィンドウ
探索者の目標達成状況および各種カスタマイズを一元管理するタブ切替式モーダルです。
- **タブ 1: クエスト (Quest Journal)**:
  - ロール別（探索者/管理者/PKer）フィルター。
  - 受注中クエストの進捗バー（例: スライム討伐 3/5）。
  - 条件達成時の「報酬を受け取る」ボタンと獲得ゴールド/経験値/アイテムのポップアップ表示。
- **タブ 2: 称号・実績 (Titles & Achievements)**:
  - アンロック済み称号一覧と未解放称号の獲得条件（ヒント）。
  - アクティブ称号の選択・装備付け替えボタン。装備中の称号バッジ表示。
- **タブ 3: ストーリー・Lore (Journal)**:
  - 解放済み古文書・日記の段落表示と未解放ページの探索ヒントテキスト。

### 5.5 モンスター図鑑ウィンドウ (Bestiary)
遭遇・討伐・捕獲したモンスターの解析情報を表示する図鑑画面です。
- **UI 構成**:
  - モンスター種別グリッド（未遭遇は `???` シルエット表示）。
  - **研究レベル表記 (Level 0 〜 3)**:
    - Level 0: シルエットのみ。
    - Level 1: 名称、属性、基本ステータス（HP、ATK等）、与ダメージ +1% ボーナス表示。
    - Level 2: 詳細スキル、耐性情報、与ダメージ +3% / 捕獲率 +2% ボーナス表示。
    - Level 3: ドロップアイテム一覧、特性リスト、与ダメージ +5% / 捕獲率 +5% / 孵化時間 10% 短縮ボーナス表示。
  - **カウント表示**: 遭遇回数、撃破回数、捕獲回数、孵化回数の統計数。

## 6. 管理者用 UI (Admin UI)
管理画面（`/admin`）は、世界の構築と運営を効率的に行うための専用インターフェースを提供します。

### 6.1 メニュー構成
- **Dungeon (ダンジョン)**:
    - ダンジョンの作成、階層情報の設定。
    - リアルタイムマップ上でのモンスター・トラップ・施設のドラッグ＆ドロップ配置。
    - **ダンジョン監視ログ**: プレイヤーの行動や戦闘イベントのリアルタイム表示。
- **Item (アイテム/倉庫)**:
    - 倉庫内のアイテム・モンスター・資材の一覧表示、ソート、フィルタリング。
    - ショップへの陳列アイテム選択と価格設定。
- **World (世界設定)**:
    - トラストネットワーク（接続中の他サーバー一覧と信頼関係の状態）の管理。
    - 世界の基本ルール（PVPのON/OFF等）のトグルスイッチ。

### 6.2 施設配置パネル
ダンジョン内に特殊施設（彫像、祭壇、釣り堀等）を建設・配置するパネルです。
- **建設資材・コスト計算機**: 必要資材（木材、石材、ゴールド）と現在の倉庫在庫の比較表示。
- **効果プリセット設定**:
  - **彫像**: 効果種別（威圧, 守護, 治癒, 強欲, 発光）の選択ドロップダウン。
  - **祭壇**: 主神（アレス, アテナ, デメテル, フォルトゥナ）の選択。
  - **釣り堀**: バイオーム別釣獲物テーブルの設定。
- **グリッドプレビュー**: ダンジョンマップ上でのドラッグ＆ドロップおよびクリックによる設置・設置解除。

### 6.3 モンスター遠征管理パネル
所有しているモンスターを遠征隊として派遣・管理するパネルです。
- **遠征隊編成画面**:
  - 倉庫から最大 3 体のモンスターを選択・配置するスロット。
  - 行き先バイオーム（Tier 1〜3）の選択。
  - 必要ゴールド・消費活力の自動計算と相性ボーナス予測の表示。
- **進行・報酬受取画面**:
  - 派遣中の遠征隊リスト、残り派遣時間（リアルタイムカウントダウンプログレスバー）。
  - 遠征完了時の「報酬受取」ボタンと獲得経験値・ゴールド・資材・たまごの獲得一覧ダイアログ。

### 6.4 操作フィードバック
- 管理アクション（配置、価格変更等）の成功・失敗をトースト通知やログで即座に通知。
- リアルタイムで変動する「基本市場価格」のグラフ表示。
