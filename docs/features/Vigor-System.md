# Vigor-System

## 1. 概要
活力（Vigor）システムは、モンスターのリソース管理と運用制限を司る仕組みです。モンスターが特定の活動（繁殖、乱入、召喚）を行うために必要な「エネルギー」として機能し、過度な連続使用を制限すると同時に、戦略的な休息とリソース配分を促します。

## 2. 基本パラメータ
- **現在活力 (Vigor)**: モンスターが現在保持しているエネルギー量。
- **最大活力 (maxVigor)**: 活力の最大値。原則として全個体一律 **100** です。
これらの値は、`StoredMonster` インターフェース（[管理者データモデル](../implementation/Admin-Data-Models.md)）にて管理されます。

## 3. 活力の消費
以下の操作を行う際、対象となるモンスター個体の活力が消費されます。活力が不足している場合、その操作を実行することはできません。

| 操作 | 消費活力 | 実行不能条件 | 参照 |
| :--- | :---: | :--- | :--- |
| **モンスター繁殖** | 20 | 活力が **20 未満** | [繁殖システム](Monster-Breeding-System.md) |
| **PK乱入（憑依）** | 50 | 活力が **50 未満** | [PKシステム](PK-System.md) |
| **管理者召喚** | 50 | 活力が **50 未満** | [管理者介入システム](Admin-Intervention-System.md) |
| **撃破・敗北** | 全て (→ 0) | - | [モンスターシステム](Monster-System.md) |

- **撃破時の挙動**: 管理者がダンジョンに配置したモンスターや、乱入中の PKer が撃破された場合、その個体の活力は即座に **0** になります。

## 4. 活力の回復と発生
減少した活力は、以下の方法で回復、または初期値が設定されます。

### 4.1 自然回復（休息）
- **場所**: [倉庫システム](Warehouse-System.md)（モンスター・ストック）に保管されている間。
- **回復量**: **1 時間につき 5 ポイント**。
- **制限**: 卵の状態では自然回復は行われません。

### 4.2 アイテムによる回復
- **アイテム**: **活力飲料 (`vigor_drink`)**。
- **効果**: 対象のモンスターの活力を **50 ポイント** 即座に回復します。
- **上限**: 最大活力（100）を超えて回復することはありません。

### 4.3 孵化時の初期値
- **孵化 (Hatch)**: 新しく孵化したモンスターは、活力が最大値の **50% (50 ポイント)** の状態で発生します。詳細は [モンスター繁殖システム](Monster-Breeding-System.md) を参照してください。

## 5. 活力低下による制限
活力が低下しているモンスターには、以下の制限が適用されます。

- **配置制限**: 活力が **0** のモンスターは、自身のダンジョン（マイ・ダンジョン）に新たに配置することができません。
- **繁殖制限**: 活力が **20 未満** の個体は、繁殖の親として選択できません。※繁殖可能回数 (`remainingBreeds`) が残っていても活力不足なら不可。
- **乱入・召喚制限**: 活力が **50 未満** の個体は、乱入（憑依）や管理者による直接召喚に使用できません。
