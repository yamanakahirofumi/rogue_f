# Ranking-System

## 1. 概要
ランキングシステムは、RogueF における非対称マルチプレイヤーおよび非同期対戦要素（マイ・ダンジョンの運営、探索者としての挑戦、PKer としての乱入）をさらに活性化させ、ユーザー間の健全な競争とモチベーションを高めるための仕組みです。
プレイヤー、管理者、および PKer がそれぞれの役割における実績を競い合い、成績に応じた特別な報酬や称号を獲得できます。

## 2. ランキングの部門
ランキングは、プレイスタイルに応じて以下の 3 つの部門（カテゴリ）に分類され、それぞれに固有の評価指標（スコア）が設定されます。

### 2.1 探索者部門 (Explorer Category)
ダンジョンを攻略し、アイテムや富を収集するプレイヤーを対象としたランキングです。
- **クリア回数ランキング (Clear Count)**:
  - 評価指標: 「マイ・ダンジョン」および「フロンティア」をクリア（最終階層の脱出）した累積回数。詳細は [機能仕様書](Functional-Specification.md) を参照。
- **プレイヤーレベルランキング (Player Level & Exp)**:
  - 評価指標: 探索者の累積獲得経験値および現在のレベル。詳細は [経験値・レベルアップシステム](Leveling-System.md) を参照。
- **ハイスコア・獲得ゴールドランキング (Gained Gold)**:
  - 評価指標: 1 回のダンジョン探索中に獲得したゴールドの最高額。

### 2.2 管理者部門 (Administrator Category)
ダンジョンを構築し、侵入者を迎え撃つ管理者を対象としたランキングです。
- **ダンジョン致死率・撃破数ランキング (Dungeon Lethality & Slains)**:
  - 評価指標: 自身が設計したダンジョン（マイ・ダンジョン）において、侵入してきたプレイヤーを撃破（デスペナルティを適用）した累積回数、および「挑戦者数に対する撃破率」。詳細は [機能仕様書](Functional-Specification.md#5-1-管理者の利益（略奪と収集）) および [管理者システム](Admin-System.md) を参照。
- **挑戦者数・人気度ランキング (Challenger Count & Popularity)**:
  - 評価指標: 自身のダンジョンに入場料を支払って進入したプレイヤーの延べ人数。
- **総資産ランキング (Total Assets)**:
  - 評価指標: 管理者の所持金、および倉庫内の全アイテム・モンスターの基本価格・価値の総和。詳細は [倉庫システム](Warehouse-System.md) を参照。

### 2.3 乱入者部門 (PKer Category)
他者のセッションに乱入し、モンスターとして暗躍するプレイヤーを対象としたランキングです。
- **PK撃破数・成功率ランキング (PK Success Count)**:
  - 評価指標: 「野良モンスター」または「憑依」形態で乱入し、対象プレイヤーを撃破した累積回数。詳細は [PKシステム](PK-System.md) を参照。
- **モンスター育成度ランキング (Monster Meta-Progression)**:
  - 評価指標: 各モンスター種別における「メタ・プログレッションレベル」の総和、または最大到達レベル。詳細は [PKシステム](PK-System.md#4-2-モンスター形態の成長-pker) を参照。

## 3. ランキングの更新とシーズン制

### 3.1 リアルタイム更新と集計サイクル
- **リアルタイム更新**: ランキングのデータ（スコア）は、ダンジョンクリア、プレイヤー撃破、レベルアップなどの各イベント発生時に即座に集計され、データベースに反映されます。
- **デイリーリセット**: 前日比やデイリー急上昇などのトレンド情報を算出するため、毎日午前 0:00（サーバー時間）に集計値が確定・更新されます。

### 3.2 シーズン制 (Seasons)
ゲーム内の経済や力関係の固定化を防ぐため、**1 ヶ月単位**での「シーズン制」を導入します。
- **シーズン期間**: 毎月 1 日から末日までを 1 シーズンとします。
- **シーズン終了時のリセット**: シーズンが終了すると、シーズン用のランキングスコアはリセットされ、すべてのプレイヤーが新たなスタートラインに立ちます（プレイヤーレベルや倉庫データ自体がリセットされるわけではありません）。
- **殿堂入り (Hall of Fame)**: 各シーズンの各部門トップ 3 に入賞したプレイヤーは、「殿堂入り」として永続的に名前と実績がゲーム内に記録されます。

## 4. ランキング報酬 (Ranking Rewards)
シーズン終了時の最終順位に応じて、各部門のプレイヤーは以下の特別な報酬を獲得できます。報酬は [拠点システム](Base-System.md) の「郵便受け（Mailbox）」または管理者倉庫に直接送付されます。

### 4.1 探索者部門の報酬
- **1位 〜 3位**:
  - 称号: 「至高の開拓者」
  - 報酬: 高級装備（`sword_magic` または `bow_elven`、および `armor_magic`）の確定獲得。
- **4位 〜 10位**:
  - 報酬: 鑑定の巻物 (`scroll_identify`) × 10、回復の薬 (`potion_hp_large`) × 5。
- **11位 〜 50位**:
  - 報酬: リンゴ (`apple`) × 30、スタミナの薬 (`potion_stamina`) × 5。

### 4.2 管理者部門の報酬
- **1位 〜 3位**:
  - 称号: 「魔宮の覇王」
  - 報酬: 特殊モンスターの卵（`dragon` または `angel`）× 1、魔力石 (`magic_stone`) × 20。詳細は [モンスター繁殖システム](Monster-Breeding-System.md) を参照。
- **4位 〜 10位**:
  - 報酬: 魔力結晶 (`magic_crystal`) × 30、魔族の血 (`demon_blood`) × 5。
- **11位 〜 50位**:
  - 報酬: 鉄材 (`iron`) × 50、石材 (`stone`) × 100。

### 4.3 PKer部門の報酬
- **1位 〜 3位**:
  - 称号: 「静かなる暗殺者」
  - 報酬: 乱入のオーブ (`orb_intrusion`) × 15、変異の薬 (`mutation_potion`) × 5。
- **4位 〜 10位**:
  - 報酬: 乱入のオーブ (`orb_intrusion`) × 5、活力飲料 (`vigor_drink`) × 3。
- **11位 〜 50位**:
  - 報酬: 乱入のオーブ (`orb_intrusion`) × 2。

## 5. API エンドポイント設計

ランキングデータを取得・管理するための REST API エンドポイントを定義します。詳細は [実装詳細](../implementation/Implementation-Details.md) を参照してください。

### 5.1 ランキング一覧の取得
- **エンドポイント**: `GET /api/ranking/{category}`
- **パスパラメータ**:
  - `category`: `explorer_clear` | `explorer_level` | `admin_lethality` | `admin_popularity` | `pker_slain` | `pker_level`
- **クエリパラメータ**:
  - `limit`: 取得件数 (デフォルト 50、最大 100)
  - `offset`: 開始位置 (デフォルト 0)
- **レスポンスデータ構造**: 後述する `RankingResponse` 型を返却します。

### 5.2 自身の順位の取得
- **エンドポイント**: `GET /api/ranking/{category}/my-rank`
- **ヘッダー**: `Authorization: Bearer <token>`
- **レスポンス**: 自身の現在の順位、スコア、および前後数名のランキングエントリを含む。

## 6. UI・UX 仕様

### 6.1 ランキングボード (Ranking Board)
- **配置**: 拠点（Base Area）の中央、および管理メニュー（`/admin/menu`）に「ランキングボード」オブジェクト（またはメニュー項目）が配置されます。
- **表示内容**:
  - 部門ごとのタブ切り替え（探索者、管理者、PKer）。
  - 各エントリには、順位（1位〜3位は金・銀・銅の王冠アイコン）、プレイヤー名、スコア、および使用しているモンスター形態や所持称号が表示されます。
  - 自身の順位は、リストの最下部にハイライト（固定表示）されて常に視認できるようになります。

### 6.2 通知演出
- シーズン終了時、ゲームにログインした際に「シーズン最終順位とリザルト」が豪華なポップアップ演出で表示されます。
- 順位が前回よりも上昇した際、ステータス画面やメッセージログに「ランキングが上昇した！」などの簡易なフィードバックが表示されます。
