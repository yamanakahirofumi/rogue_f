# Combat-System

## 1. 戦闘の基本コンセプト
RogueFの戦闘は、従来のターン制ローグライクとは異なり、**リアルタイム/アクティブタイム制**を採用します。プレイヤーとモンスターは、それぞれの「待機時間（クールタイム）」が経過するたびに行動が可能になります。

## 2. バトルシステム詳細

### 2.1 リアルタイム性
- 全てのエンティティ（プレイヤー、モンスター）は独立したタイマーを持ちます。
- 行動（攻撃、アイテム使用等）を行うと、その行動に応じたクールタイムが発生します。

### 2.2 攻撃と待機時間
- **アクションインターバル**: 攻撃行動には待機時間が発生します。プレイヤーの攻撃速度は「敏捷性」に依存します。詳細は **[アクションシステム](Action-System.md)** を参照してください。
- **移動のコスト**: 8 方向（上下左右、斜め）の移動におけるインターバルおよびスタミナ消費は**一律（同一）**です。
- **モンスターの攻撃インターバル**: モンスターの種類により 1.5秒〜3.0秒（各モンスターの個別値については [モンスターマスターリスト](Monster-Master-List.md) を参照）。
- クールタイム（インターバル）中は次の攻撃が行えません。UI上でプログレスバー等によりクールタイムを表示します。
- 攻撃コマンドおよびレスポンスの詳細は [実装詳細](../implementation/Implementation-Details.md#22-プレイヤー情報) を参照してください。

### 2.3 ダメージ計算式
ダメージ量は以下の式をベースに算出します。

`ダメージ = ((攻撃力 * 乱数(0.9〜1.1)) - (防御力 / 2)) * 属性倍率`

- **属性倍率**: 攻撃側と防御側の属性相性に基づいて決定されます。詳細は **[属性システム](Attribute-System.md)** を参照してください。
- 最小ダメージは 1 とします。

### 2.4 命中と回避
命中判定は、攻撃側の「器用さ」と防御側の「素早さ」を用いて算出します。

- **命中率計算式**:
    - `最終命中率(%) = 基礎命中率 * 状態異常補正`
    - `基礎命中率 = Math.min(100, Math.max(50, (90 + (自身の器用さ - 敵の素早さ) * 2) - 距離補正 - 敵の回避率))`
    - **状態異常補正**:
        - **盲目 (`BLINDNESS`)**: 命中率が **0.5 倍** に低下します。詳細は [状態異常システム](Status-Effect-System.md) を参照してください。
        - **通常**: **1.0 倍**。
- **距離補正 (Ranged Accuracy Decay)**:
    - 遠距離攻撃において、対象との距離が **2 マス** を超える場合、1 マス離れるごとに命中率が **5%** 減少します。
    - `距離補正 = Math.max(0, 距離 - 2) * 5`
- **回避率 (Evasion Rate)**:
    - 特性（`aquatic` 等）や属性（水属性等）によって付与される固定の回避ボーナスです。
- **制約**:
    - 基礎命中率の段階で下限 50%、上限 100% の制限が適用されます。状態異常補正は、この制限が適用された後の値に乗算されます。

### 2.5 クリティカルヒット
攻撃時に一定の確率でクリティカルヒットが発生します。

- **クリティカル発生率**: 攻撃側の「器用さ」および「運 (Luck)」に依存して決定されます。
    - `クリティカル発生率(%) = (器用さ * 0.5) + (運 * 0.2)`
- **効果**: 通常よりも高いダメージを与えます。
    - `クリティカルダメージ = (基本ダメージ) * 1.5`
    - ※小数点以下は**切り捨て**。
- **判定**: `CombatResult` の `critical` フィールドによってフロントエンドに通知されます。

### 2.6 攻撃射程 (Attack Range)
攻撃が届く範囲は、装備している武器やモンスターの種類によって決まります。

- **近接攻撃 (Melee)**:
    - 射程: **1**
    - 自身の周囲 8 マスが対象となります。武器を装備していない場合や、通常の剣などの射程は 1 です。
- **遠距離攻撃 (Ranged)**:
    - 射程: **2 以上** (アイテムや個体別に定義)
    - 弓や魔法などの攻撃が該当します。
    - **視線の制約 (Line of Sight)**: 攻撃者と対象の間に「壁」などの遮蔽物がある場合、射程内であっても攻撃は届きません。
    - **射線の遮蔽**: 発射された遠距離攻撃は、ターゲットに到達するまでの経路上に「壁」だけでなく、**他のモンスターやプレイヤー（エンティティ）が存在する場合も遮蔽され**、その手前のエンティティに命中します。
    - **判定アルゴリズム**: 直線的な視界および射線の判定には **Bresenham's line algorithm** を使用します。

## 3. 投擲システム (Throwing System)

アイテムを投げて遠距離の敵にダメージを与えたり、特殊な効果を及ぼしたりする仕組みです。

### 3.1 投擲の基本仕様
- **射程**: 一律 **10 マス**。
- **弾道**: 直線的。壁やエンティティによって遮蔽されます（Bresenham's line algorithm を使用）。
- **着弾時の挙動**:
    - エンティティ（プレイヤー、モンスター）に命中した場合：アイテムは消滅（破壊）します。
    - 壁に当たった、または最大射程に達した場合：そのマスの床にアイテムがドロップされます。ただし、一部の「壊れやすい」アイテムはドロップせずに消滅する場合があります。

### 3.2 投擲ダメージ計算式
投擲によるダメージは以下の式で算出されます。

`投擲ダメージ = ((投擲威力 + (自身の攻撃力 / 4) * 乱数(0.9〜1.1)) - (敵の防御力 / 2)) * 属性倍率`

- **投擲威力 (Throwing Power)**: アイテムごとに設定された固有の攻撃値。詳細は [アイテムマスターリスト](Item-Master-List.md) を参照してください。
- **属性倍率**: 投げたアイテム自体の属性（武器等の場合）に基づいて計算されます。
- 最小ダメージは 1 とします。

### 3.3 投擲の命中率
投擲攻撃の命中判定は、通常の射撃攻撃よりも低めに設定されています。

- **命中率計算式**:
    - `最終投擲命中率(%) = 基礎投擲命中率 * 状態異常補正`
    - `基礎投擲命中率 = Math.min(100, Math.max(50, (80 + (自身の器用さ - 敵の素早さ) * 2) - 距離補正 - 敵の回避率))`
- **距離補正**: 1 マス離れるごとに命中率が **5%** 減少します（初速の減衰）。
    - `距離補正 = (距離 - 1) * 5`

## 4. モンスターAIパターン

モンスターの種類ごとの具体的な AI パターンの割り当てについては、**[モンスターマスターリスト](Monster-Master-List.md)** を参照してください。

モンスターは以下のいずれかの思考ルーチンを持ちます。

### 4.1 積極的 (Aggressive)
- プレイヤーを視界（10 マス）に捉えると、最短距離で接近し、隣接すると攻撃を繰り返します。
- **隠密による影響**: プレイヤーが「闇 (Dark)」属性を所持している場合、感知距離が **20% 減少（10 マス → 8 マス）** します。詳細は [属性システム](Attribute-System.md) を参照してください。

### 4.2 遠距離型 (Ranged)
- プレイヤーと一定の距離（4 マス）を保とうとします。
- 距離が近い場合は離れ、離れすぎている場合は近づきます。
- 射程内に入ると遠距離攻撃を行います。

### 4.3 臆病 (Cowardly)
- HPが一定割合（25%）以下になると、プレイヤーから逃げるように移動します。

### 4.4 ランダム (Random)
- 特定の目的を持たず、ランダムな方向に移動します。

## 5. 状態異常
戦闘を深めるため、スタン、毒、鈍足などの状態異常を定義します。
